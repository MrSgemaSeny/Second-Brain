# ADR-012: Стандартизация архитектуры хуков .agents Lifecycle Hooks

## Статус
Принято (Accepted) — 2026-08-28

## Контекст
При работе нескольких AI-агентов в разных проектах (`MrDevCourses`, `MeDev`, `Valeur`, `JF-1C`) возникали риски:
1. Потеря контекста при старте новой сессии (агент забывал правила и Second Brain).
2. Нарушение workflow (пуш кода без записей в журнал или при непройденных тестах).
3. Завершение сессии агента с незакоммиченными изменениями в рабочей копии.
4. Сжигание токенов из-за использования медленных shell-утилит (`cat`, `grep`) вместо нативных инструментов Antigravity.

## Решение
Внедрить универсальный стандарт `.agents/hooks.json` во всех репозиториях:
1. **PreInvocation (`pre-invocation.ps1`)**: На первом шаге сессии инжектирует в системный контекст `.agents/CONTEXT.md` и файлы `context/*.md` из `Brain's protocol - second brain`.
2. **PreToolUse (`safety-gate.ps1`)**: Блокирует команды чтения файлов через терминал (`cat`, `head`, `sed`, `ls`, `grep`) и деструктивные git-команды (`push --force`, `reset --hard`), разрешая стандартные коммиты и пуши.
3. **PreToolUse (`enforce-workflow.ps1`)**: Перехватывает `git push` и проверяет наличие файла в `journal/` с поддержкой 24-часового окна (защита от полуночного сдвига дат).
4. **Stop (`stop-check-commits.ps1`)**: Проверяет статус репозитория и Second Brain перед завершением хода; при наличии измененных или неотслеживаемых файлов возвращает `decision: continue`.

## Последствия
- **Положительные:** Гарантированное соблюдение протокола Brain's Protocol, нулевая вероятность потери кода или отсутствия логов в журнале, максимальная эффективность расхода токенов.
- **Отрицательные:** Необходимость поддерживать актуальный `.gitignore` для предотвращения ложных блокировок на временных файлах.
