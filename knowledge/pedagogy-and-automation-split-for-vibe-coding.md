# Педагогика вайбкодинга и разделение автоматизации в LMS

## 1. Суть концепции

В обучении вайбкодингу и разработке начинающих (16–25 лет) критически важно понимать, что студент покупает **не синтаксис языка, а трансформацию собственной идентичности** («я тот, кто способен задеплоить живой продукт онлайн»).

Главный барьер — **страх отстать (FOMO) и стыд показаться некомпетентным**. Если платформа не снимает этот стыд в первые 60 минут, наступает отвал.

## 2. Матрица разделения: Платформа vs Ментор

```
+-------------------------------------------------------------------+
|                        ПЛАТФОРМА (LMS)                            |
|  - Drip расчёт доступа к урокам по формуле СУБД                  |
|  - Приём GitHub & Live Demo ссылок                                |
|  - AI-грейдинг кода + AST Security Guard                          |
|  - Поиск ответов в конспектах через Гибридный RAG (RRF)          |
|  - Stuck Detection (мониторинг неактивности >= 3 дней)            |
+---------------------------------+---------------------------------+
                                  | Алерты о застревании / Escalation
                                  v
+-------------------------------------------------------------------+
|                     ЖИВОЙ МЕНТОР (DISCORD)                        |
|  - Первый онбординг-созвон (снятие психологического барьера)      |
|  - Поддержка при выгорании и потере мотивации                     |
|  - Разбор тупиков, когда студент не может сформулировать вопрос   |
|  - Разбор концептуальных бизнес/архитектурных развилок            |
+-------------------------------------------------------------------+
```

## 3. Ключевые паттерны удержания (Retention Patterns)

1. **Дофаминовый инжект (Урок 1)**: Результат должен быть опубликован онлайн в первые 45 минут (деплой на Vercel / GitHub Pages). Студент делится ссылкой с друзьями, фиксируя статус создателя.
2. **Обучение метанавыку работы с AI**: До автономии студент должен освоить паттерн **Error-Loop** (как скопировать ошибку из консоли браузера и скормить её LLM с правильным контекстом).
3. **UX-эскалация**: *«Сначала спроси ИИ-тьютора $\rightarrow$ если не помогло за 2 шага $\rightarrow$ кнопка эскалации ментору»*. Это защищает ментора от выгорания на синтаксических вопросах.
4. **Stuck Detection**: Автоматическое обнаружение простоя более 72 часов без активных действий и отправка персонального пуша студенту + Telegram-алерта ментору.
