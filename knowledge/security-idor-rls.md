# Безопасность эндпоинтов и защита от IDOR

## Описание
В системе реализована строгая защита от Insecure Direct Object Reference (IDOR) и Row-Level Security (RLS) для защиты данных пользователей.

## Реализация
- **Без передачи userId**: Все эндпоинты профиля (например, `/v1/profile/**`) **не принимают** `userId` из параметров URL.
- **Извлечение из токена**: Идентификатор пользователя извлекается строго из проверенного JWT-токена на стороне бэкенда (`SecurityUtils.getCurrentUserId()`).
- **Row-Level Security**: В сервисах обновления и изменения данных каждый запрос модифицирует записи исключительно для текущего авторизованного пользователя.

## Обработка ошибок
- Используется `GlobalExceptionHandler`. 
- Система не отдает сырые StackTrace на клиент. Все ошибки маппятся в стандартизированный JSON (`code`, `message`), что предотвращает утечку деталей реализации приложения.
