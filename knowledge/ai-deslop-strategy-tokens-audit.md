# AI Deslop: Стратегия → Токены → Аудит в UI-инженерии

## Суть концепции
Типичная деградация интерфейсов, генерируемых LLM ("AI Slop"), вызвана абстрактными промптами вроде *"сделай современный красивый UI в тёмной теме"*. Модель генерирует избыточные тени, неоновые градиенты, 6+ неконсистентных размеров шрифтов и декоративные Bento-сетки, непригодные для восприятия плотного технического контента.

Инженерный подход к устранению "слопа" (Deslop) строится на трёх жестких фазах:
```
1. СТРАТЕГИЯ (Кто ЦА? Какова плотность? Какая задача?)
     ↓
2. ТОКЕНЫ (DESIGN.md контракт: 4 уровня типографики, палитра, радиусы)
     ↓
3. СТРОГИЙ АУДИТ (WCAG AA контраст, удаление лишних декораций, a11y)
```

## 1. 4-уровневая типографическая шкала
Вместо 6+ размеров шрифтов используется строгая компактная шкала:
- **`text-xs` (12px / font-mono):** Метаданные, бейджи, теги, счетчики, подписи.
- **`text-sm` (14px):** Основной текст интерфейса, навигация, кнопки, списки.
- **`text-base` (16px):** Заголовки секций, подзаголовки, лид-абзацы.
- **`text-lg` или `text-xl` (18-20px):** Главные заголовки страниц (Hero / Page Title).

**Иерархия строится через насыщенность и контраст:**
- `font-medium` для текста, `font-semibold` для заголовков.
- `text-zinc-100` (первичный фокус) → `text-zinc-300` (основной контент) → `text-zinc-400`/`text-zinc-500` (второстепенные данные).

## 2. Bento Grid ≠ Дизайн-сигнатура
Bento Grid — инструмент группировки разнородных карточек, но не самоцель.
- **Антипаттерн:** Растягивать пустой блок на `col-span-2` только ради создания "модной сетки".
- **Паттерн:** Использовать строгие линейные списки или однородные сетки (`grid-cols-1 md:grid-cols-2 lg:grid-cols-3`), где геометрия определяется исключительно объемом данных.

## 3. Светотень и глубина без мыльных теней
Вместо размытых `shadow-xl`:
- Контраст поверхностей: подложка `#0a0a0c` + карточка `#18181b` (контраст > 14 единиц).
- Тонкая рамка: `border border-white/5` или `border-white/10`.
- Верхний световой блик (Top Inset Highlight): `shadow-[inset_0_1px_0_rgba(255,255,255,0.04)]`.

## 4. Чеклист аудита перед сдачей UI
1. [ ] Нет ли шрифтов крупнее `text-xl` в рабочей зоне приложения?
2. [ ] Все ли цвета фона и границ взяты из токенов `DESIGN.md`?
3. [ ] Есть ли видимые клавиатурные фокусы (`ring-2 ring-white/20`) на интерактивных элементах?
4. [ ] Проходят ли текстовые элементы проверку контраста 4.5:1 (WCAG AA)?
5. [ ] Нет ли нефункциональных градиентов или кислотных акцентов?
