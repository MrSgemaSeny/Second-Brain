# Парсинг PDF-резюме (Извлечение текста)

## Описание
Функционал интеллектуального парсинга резюме позволяет извлекать текст из старых, неструктурированных PDF-резюме пользователя для автоматического маппинга в структурированный профиль.

## Технологии
Для извлечения текста используются библиотеки **Apache Tika** и **PDFBox**.

## Подводные камни и UX
- **Точность**: Данные из резюме зачастую имеют непредсказуемый формат. Ожидаемая точность парсинга составляет 60-70%.
- **Процесс валидации**: Из-за возможных ошибок распознавания, главным правилом UX является то, что пользователь должен самостоятельно подтверждать и редактировать распознанные данные перед их сохранением.
