# Интеграция с GitHub API и управление Rate Limit

## Описание
В проекте MeDev реализована интеграция с GitHub API для автоматического извлечения данных пользователя: репозитории, статистика активности (коммиты, pull requests) и используемые языки программирования. 

## Техническое решение и обход ограничений (Rate Limiting)
- **Проблема**: У GitHub API существует строгий лимит (Rate Limit) — 5000 запросов в час. При активном использовании системы квота может быть быстро исчерпана.
- **Решение (Кэширование)**: Для предотвращения исчерпания лимитов ответы от GitHub API кэшируются в **Redis** на 1 час. Это критически важно, иначе пользователи быстро "положат" квоту на генерацию статистики.

## Безопасность
Токены GitHub (OAuth) сохраняются в базе данных в **зашифрованном виде**.
