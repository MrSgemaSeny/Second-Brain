# AI Deslop Tools & Frontend Craft Skills

## Суть
AI-генераторы кода (Claude, GPT, Cursor) часто используют шаблонные, "дефолтные" паттерны (slop). В коде это выражается в виде пустых catch, чрезмерного defensive programming, лишних логов. В дизайне — в виде фиолетовых градиентов, шрифта Inter везде, дефолтном shadcn-выравнивании и отсутствии оптической иерархии (веса/отступов).
Инструменты деслопа и Agent Skills направлены на подавление этих "дефолтов" и принудительное включение намерений (intent) и craft-дизайна.

## Когда применять
1. **Инфраструктура (CI/CD / Локальный анализ):** Когда кодовая база начинает обрастать шаблонными проверками, `console.log` или "капитанскими" комментариями.
2. **Frontend Разработка (UI/UX):** Перед началом верстки новых страниц или дашбордов. ИИ-агент должен предварительно ознакомиться со скиллом деслопа (например, загрузить `SKILL.md`), чтобы зафиксировать сетку, палитру и правила отступов.

## Ключевые Инструменты и Скиллы

### 1. Code-Deslop (Чистка логики и кода)
- **`dabit3/deslop`**: CLI-сканер (`npx deslop`). Проверяет `git diff` относительно `main`. Ловит High/Medium/Low severe паттерны ИИ-кода (лишние try-catch, console.log, очевидные комменты). Не ломает код, просто указывает на недочёты.
- **`agent-sh/deslop`**: Продвинутый CLI (через `agentsys`). Имеет 3 фазы поиска (от регулярок до AST и вызова внешних линтеров). Умеет делать auto-fix с прогоном тестов и откатом (`git restore`), если тесты упали.

### 2. Frontend-Design-Deslop (Agent Skills для UI/UX)
- **`Dammyjay93/interface-design`**: Обязательный скилл для разработки интерфейсов (SaaS, дашборды).
  - *Суть:* Убивает плоскость. Иерархия строится через weight (начертание) и цвет, а не только через size. Заставляет ИИ задавать сетку токенов (density, spacing, depth).
  - *Правило:* Никаких хардкод-классов Tailwind там, где должна быть система.
- **`funboy322/avoid-ai-design`**: Аудит-скилл для ИИ. Имеет 2 режима (`rewrite` и `detect`). Умеет градировать находки: P0 (явный след AI: градиент, Inter), P1 (дефолтный UI: закругленные везде карточки с тенями), P2 (проблема с ритмом отступов).
- **`samber/cc-skills (frontend-design-deslop)`**: Скилл "Стратегия-сначала". Сначала ИИ определяет позиционирование бренда (adjectives), потом выводит токены (DESIGN.md), и только затем пишет код.

## Интеграция в наш Workflow
- Хранить нужные `SKILL.md` файлы в локальной директории `.agents/`.
- Вызывать их через системные промпты или добавлять в контекст при крупных frontend-задачах.
- Для ревью-пулреквестов можно использовать CLI-тулзы или `avoid-ai-design` в режиме `detect`.
