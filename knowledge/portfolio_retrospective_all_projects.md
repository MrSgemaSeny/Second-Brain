# Инженерная Ретроспектива и Полнейший Обзор Портфолио (All my projects)

## 1. Введение: Проекты как жизненный путь

Техническое портфолио — это не просто набор репозиториев, это инженерный дневник. Проанализировав директорию `All my projects`, можно отследить фундаментальный профессиональный рост: от ручного управления JDBC-соединениями до распределенных микросервисных архитектур и SaaS-платформ уровня Production-Ready.

Главный человеческий результат, заложенный в этом коде — осознание того, что реализация идеи требует лишь времени и непрерывного фокуса. Студенты и джуниоры, глядя на этот объем работы, видят не просто "умного инженера", а человека, который начал раньше и не остановился. Это формирует подлинный авторитет ментора, который учит не по книгам, а на основе сотен часов, проведенных за отладкой, проектированием БД и борьбой с архитектурной энтропией.

## 2. Глубокий Архитектурный Разбор Проектов

В директории представлены 5 ключевых систем и один фундаментальный манифест. Все проекты объединяет строгий технологический почерк: Java (Spring Boot) на бэкенде, React (TypeScript, FSD) на фронтенде и PostgreSQL как Source of Truth.

### 2.1. ZhanFinance (JF-1C) — Enterprise B2B SaaS CRM
*Уровень: Production-Ready (Level 4)*

Флагманский продукт, демонстрирующий способность инженера закрывать потребности реального бизнеса (консалтинг и бухгалтерия).
- **Архитектура**: Строгий модульный монолит (14 модулей, 36 сущностей БД).
- **Сложность**: Сложные пайплайны задач с auto-reopen логикой, система генерации официальных документов РК (PDF) с поддержкой кириллицы, 6-уровневая ролевая модель.
- **Безопасность**: Жесткий Defense-in-Depth. Row-Level Security через `CrmAccessService`, 2FA TOTP, маскирование чувствительных данных в Audit Logs, защита от IDOR.
- **Вывод**: Проект доказывает умение строить надежные системы с учетом финансовых транзакций, где цена ошибки — реальные деньги и штрафы клиентов.

### 2.2. MeDev (DevProfile) — Data-First AI SaaS для Инженеров
*Уровень: Pre-Launch / Private Beta (v1.0.0-RC)*

Платформа, объединяющая данные GitHub и алгоритмы LLM (Llama 3.3) для автоматизации карьерного пути разработчика.
- **Интеграция с AI**: Демонстрация того, как нужно работать с LLM в продакшене. Реактивный стриминг (SSE) через Groq API, маскирование PII, детерминированный парсинг.
- **Производительность**: Двухуровневое кэширование (L1 Caffeine in-memory для мгновенной отдачи + L2 Redis для сессий). Vanity-URL профили генерируются с микросекундными задержками.
- **Криптография**: AES-256-GCM шифрование пользовательских токенов, пессимистические блокировки (`PESSIMISTIC_WRITE`) для предотвращения race conditions.
- **Вывод**: Глубокое понимание concurrency, кэширования и интеграции AI-инструментов в жесткие рамки бизнес-логики.

### 2.3. Valeur — Multi-Tenant ATS & AI Hiring Platform
*Уровень: Heavy Production-Ready MVP (Level 2)*

Переход от монолитной к микросервисной архитектуре. Система автоматизации рекрутинга с мультитенантностью.
- **Архитектура**: 5 микросервисов + Spring Cloud Gateway. Строгая изоляция данных по `tenant_id` (TenantContext).
- **Связанность**: Взаимодействие через `RestClient` с валидацией `X-Internal-Token`.
- **Логика**: Kanban-доски с SLA-контролем, AI-скоринг резюме с отказоустойчивым эвристическим fallback-алгоритмом.
- **Вывод**: Успешное преодоление барьера микросервисов, понимание проблем распределенных транзакций и межсервисной аутентификации.

### 2.4. MrDevCourses — Educational LMS & Vibe-Coding Platform
*Уровень: Strong Educational MVP (Level 3)*

LMS-платформа, созданная для обучения и менторства.
- **Инновации**: Интеграция RAG (Retrieval-Augmented Generation) на базе `pgvector` и FTS для контекстного тьютора. AI-грейдер с проверкой AST-дерева на безопасность (блокировка `Runtime.exec`).
- **Сложность БД**: Расчет drip-контента (доступности уроков) полностью на уровне SQL-запросов, без фоновых планировщиков, что снижает нагрузку на JVM.
- **Вывод**: Инструмент, кристаллизующий менторский подход. Технически изящное решение для образовательного процесса.

### 2.5. Envie — Персональная База Знаний и ОС
*Уровень: Personal Headquarters*

Безоблачный, приватный инструмент "для себя".
- **Философия**: Zero-latency, без чужой авторизации, без SaaS-ограничений.
- **Технологии**: Оптимизированный HTML5 Canvas 3D (без WebGL overhead), Emil Kowalski motion physics, локальный файловый движок.
- **Вывод**: Показатель инженерной гигиены и стремления к суверенитету данных. Программист, который пишет инструменты для своей же продуктивности, обладает высочайшим уровнем рефлексии.

## 3. Технологический Почерк и Архитектурные Принципы

Анализ всех проектов выявляет четкие паттерны, которые формируют "инженерный почерк" автора:

1. **Database-First Thinking**: Понимание того, что состояние системы живет в базе данных. Миграции (Flyway) строго неизменяемы. Использование сложных возможностей СУБД (векторный поиск, триграммы, Row-Level Security, вычисления интервалов).
2. **Security by Design**: Безопасность не прикручивается в конце. Защита от IDOR, строгий RBAC, маскирование логов аудита и Rate Limiting присутствуют на уровне ядра во всех системах.
3. **Монолит до Микросервисов**: Автор понимает, что микросервисы (Valeur) нужны только там, где есть реальная потребность в независимом масштабировании тенантов. В остальных случаях (JF-1C, MeDev, MrDevCourses) используется строгий, хорошо структурированный модульный монолит (FSD на фронтенде).
4. **Контроль задержек (Latency Tolerance)**: Применение L1/L2 кэширования, стриминг ответов (SSE) для LLM, оптимизация 3D-графики под старые GPU (Envie).
5. **Full-Stack Автономия**: Способность в одиночку вытянуть продукт от схемы БД до деплоя на Fly.io/Render и настройки CI/CD пайплайнов в GitHub Actions.

## 4. Резюме Ментора: "Я — настоящий результат"

Этот обзор — доказательство того, что путь от простого Telegram-бота на Raw JDBC до распределенной мультитенантной ATS-системы с AI-скорингом проходится исключительно через труд, ошибки и постоянную итерацию. 

Нет магического знания, есть только системная работа. Проекты в этой директории показывают студентам, что сложные системы строятся слой за слоем: сначала вы понимаете пулы соединений, затем транзакции, затем архитектуру слоев, потом кэширование и распределенные системы. 

Авторитет строится на коде, который работает в продакшене. Портфолио демонстрирует высший пилотаж инженерной культуры: документация (ADR), тесты (сотни пройденных JUnit/Vitest), CI/CD и бескомпромиссное отношение к качеству. Это не просто проекты — это материализация идеи о том, что фокус и дисциплина побеждают всё.
