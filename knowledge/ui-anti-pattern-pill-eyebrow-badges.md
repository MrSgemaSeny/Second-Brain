# UI Антипаттерн: Декоративные Pill / Eyebrow Бейджи (AI Slop Pill Tags)

## Суть антипаттерна
Шаблонное добавление над каждым H2-заголовком секции капсуловидной плашки со скруглением `rounded-full`, полупрозрачной рамкой и декоративной точкой/кружком (например, `● ПОЧЕМУ ВЫБИРАЮТ АУТСОРС`, `● О КОМПАНИИ`, `● ТАРИФЫ ОБСЛУЖИВАНИЯ`):

```tsx
/* АНТИПАТТЕРН: Шаблонный визуальный шум AI */
<div className="inline-flex items-center gap-2 px-4 py-1.5 rounded-full border border-white/20 text-white/90 text-xs font-bold uppercase tracking-widest mb-6">
  <span className="w-2 h-2 rounded-full bg-brand-beige" />
  ПОЧЕМУ ВЫБИРАЮТ АУТСОРС
</div>
<h2 className="text-5xl font-black uppercase">...</h2>
```

---

## Почему это признано антипаттерном

1. **AI Slop & Шаблонность:**
   - Капсульные бейджи над каждым блоком стали главным маркером «галлюцинированного AI-дизайна» (дефолтные шаблоны Tailwind UI / Framer / Webflow). 
   - Интерфейс начинает выглядеть однотипно, дешево и перегружено, теряя уникальный характер бренда.

2. **Семантическая избыточность:**
   - Бейдж просто дублирует смысл следующего за ним H2-заголовка. Читатель тратит когнитивный ресурс на чтение одного и того же посыла дважды.

3. **Ложная метафора статуса:**
   - Точка (`dot`) в интерфейсах исторически означает **состояние системы в реальном времени** (`● Online`, `● Server Running`, `● Recording`, `● Live Update`).
   - Использование точки рядом со статичным заголовком секции сбивает пользователя и обесценивает настоящие статус-индикаторы.

4. **Дробление вертикального ритма:**
   - Плашка съедает полезный вертикальный отступ (от 32px до 56px с учетом марджинов), отодвигая ключевой продающий оффер ниже первого экрана.

---

## Где допустимо (Исключения)

- **Динамический статус реального времени:** `● В сети`, `● Идет обработка`, `● Доступно 3 места`.
- **Селектор / Интерактивный фильтр:** Кликабельный чип с состоянием `active / inactive`.
- **Маркировка тарифа / скидки:** `ПОПУЛЯРНЫЙ ТАРИФ`, `-20% ДО КОНЦА МЕСЯЦА`.

---

## Правильная альтернатива

### 1. Прямой чистый заголовок (Рекомендуется)
Убрать капсулу и точку полностью. Заголовок первого порядка сам формирует контекст за счет массы и контраста:

```tsx
<h2 className="text-4xl sm:text-5xl lg:text-6xl font-black uppercase leading-[1.1] tracking-tight text-white mb-6">
  Надежная бухгалтерия <br />
  <span className="text-brand-beige/50">без штатных рисков</span>
</h2>
```

### 2. Лаконичный типографический Eyebrow (если рубрикатор строго обязателен)
Без рамок, овалов и точек — чистый текст с акцентом через трекинг и цвет:

```tsx
<p className="text-xs font-bold uppercase tracking-[0.2em] text-brand-beige/60 mb-3">
  Аутсорсинг бухгалтерии
</p>
<h2 className="text-4xl sm:text-5xl font-black uppercase text-white">...</h2>
```

---

## Правило для AI-агентов системы Second Brain
> **Запрещено** генерировать декоративные `rounded-full` pill-бейджи с точками над заголовками секций. Иерархия строится исключительно через типографическую шкалу DESIGN.md (H1/H2, кегль, трекинг, цвет), а не через декоративные обертки.
