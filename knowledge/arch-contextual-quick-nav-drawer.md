# Паттерн: Контекстная навигация (Quick-Nav Drawer) без размонтирования плеера

## Суть
Обеспечение быстрого доступа студента к справочным материалам курса (глоссарий терминов с примерами кода, карта прогресса, траектория обучения) без потери состояния и сброса видео-плеера YouTube (iframe).

## Архитектура фронтенда
```
LessonPage (Основной экран урока)
   ├── YouTube Embed Iframe (Сохраняет позицию воспроизведения)
   ├── MarkdownViewer (Контент урока)
   ├── LessonContextPanel (Контекстные карточки терминов к текущему уроку)
   │      └── Клик по термину ──► quickNav.openTerm(termId)
   │
   └── QuickNavDrawer (Рендерится как fixed overlay)
          ├── Режим 1: GlossaryView (Полнотекстовый поиск + фильтры по категориям + аккордеоны с кодом)
          ├── Режим 2: ProgressView (Дни курса, статус разблокировки, стрик)
          └── Режим 3: RoadmapView (Интерактивная карта траектории обучения)
```

## Ключевые преимущества
1. **Zero Layout Reflow:** Выдвижной ящик позиционируется поверх контента (`fixed inset-y-0 right-0 z-50`), не деформируя сетку плеера и текста.
2. **Deep Linking:** Студент может нажать на термин прямо во время изучения темы урока, и ящик откроется с уже развернутой карточкой нужного термина.
3. **FSD Compliance:** Виджет `widgets/quick-nav` управляется через легковесный `QuickNavContext`, обеспечивая чистую архитектурную границу без циклических импортов.
