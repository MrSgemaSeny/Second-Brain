# Генерация PDF из HTML (Thymeleaf + Flying Saucer)

## Описание
Для генерации PDF-резюме используется связка HTML-шаблонизатора и рендерера в PDF на стороне сервера.

## Технологический стек
- **Thymeleaf**: Используется для создания HTML-шаблонов (например, `classic.html`), в которые "впрыскиваются" данные профиля пользователя.
- **Flying Saucer**: Выполняет рендеринг готового HTML-документа в байтовый массив PDF.

## Подводные камни
- **Поддержка кириллицы**: При использовании Flying Saucer встроенные шрифты по умолчанию могут не поддерживать русский язык. 
- **Решение**: Необходимо обязательно встраивать `.ttf` файлы шрифтов (например, Roboto) через правило `@font-face` непосредственно в HTML-шаблоны.
- **Ограничения (Лимиты генерации)**: Ограничение для бесплатных пользователей проверяется через счетчики в Redis (например, `resume:gen:userId:date`).
