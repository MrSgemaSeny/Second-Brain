# Паттерны B2C LMS: Витрина курсов, Hover-превью и Интерактивный Syllabus

## 1. Архитектура Discovery-слоя (Витрины курсов)
Современные B2C платформы (Udemy, Frontend Masters, Steam, Netflix) используют паттерн быстрого погружения:
- **Hover Video Teaser**: При наведении на карточку курса постер бесшовно сменяется коротким превью/тизером без звука.
- **Компактная информационная плотность**: Карточка должна мгновенно передавать 4 вещи: стек технологий, сложность, длительность (модули/часы) и формат.
- **Минималистичный фильтр-бар**: На ранних этапах (до 10 курсов) не перегружать интерфейс пустыми категориями и счётчиками, используя три контрола:
  [Поиск по названию]  [Уровень ▾]  [Формат ▾]

## 2. Анатомия B2C лендинга курса (/courses/:slug)

`
+-------------------------------------------------------------+-----------------------+
|  Хлебные крошки (Каталог → Название)                        |  [Постер / Трейлер]   |
|  H1 Заголовок курса + Краткий слоган                        |                       |
|  Плашка автора (Mr Developer) + Теги стека + Уровень         |  [Кнопка Записаться]  |
|-------------------------------------------------------------|  (или Продолжить + %) |
|  [✓] Чему вы научитесь (Сетка результатов)                  |                       |
|-------------------------------------------------------------|  3-4 Ключевых факта   |
|  [i] Кому подойдет курс и требования                        |  - Уроков / Часов     |
|-------------------------------------------------------------|  - Формат             |
|  Программа курса (Аккордеон модулей)                        |  - Сложность          |
|  - Кнопка "Развернуть / Свернуть всё"                       |                       |
|  - Модуль 1 (Раскрыт по умолчанию)                          |  [Поделиться]         |
|    • Урок 1 [Видео] [15 мин] [Бесплатно]                    |                       |
|    • Урок 2 [Квиз] [10 мин] [Замок]                         |  [Sticky Sidebar 30%] |
|  - Модуль 2 (Свёрнут)...                                    |                       |
|-------------------------------------------------------------|                       |
|  FAQ (Частые вопросы)                                       |                       |
+-------------------------------------------------------------+-----------------------+
`

## 3. Правила FSD декомпозиции
- widgets/course-curriculum/CourseCurriculumAccordion.tsx — изолированный виджет аккордеона с мемоизацией и подсчётом времени.
- widgets/course-sidebar/CourseStickyCard.tsx — плавающий сайдбар с переключением состояний (Гость / Студент без записи / Зачисленный студент).
- widgets/course-faq/CourseFaqSection.tsx — аккордеон часто задаваемых вопросов.
