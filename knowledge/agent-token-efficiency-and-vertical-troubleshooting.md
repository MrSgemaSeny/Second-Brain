# Agent Token Efficiency & Vertical Slice Troubleshooting

_Обновлено: 2026-09-01_

## Контекст и Проблема
При решении локальных задач полного стека (например: *«сделай так, чтобы после обновления страницы меня не кидало на логин, сессия 7 дней / 30 дней»*) агент может уйти в избыточное горизонтальное сканирование кодовой базы:
- 8 поисковых запросов (`*auth*`, `*apiClient*`, `*userApi*`).
- Чтение 29 файлов (роутер, ProtectedRoute, страницы LoginPage, перехватчики Axios).
- Время сессии: 7 минут вместо оптимальных 1.5–2 минут.

Итоговый результат был 100% корректен (тесты зеленые, сессия зафиксирована, коммиты отправлены), но расход токенов и времени оказался в 4–5 раз выше оптимального.

---

## 1. Анатомия перерасхода: Горизонтальное сканирование vs Вертикальный срез

### Антипаттерн: Горизонтальное блуждание
Агент не знает точных границ фичи и начинает исследовать проект «в ширину»:
`Поиск всех auth-файлов -> сканирование всего дерева router -> чтение всех страниц -> чтение клиентских оберток -> попытка догадаться, где баг`.

### Паттерн: Вертикальный целевой срез (Vertical Slice)
Авторизация и сессии — это строгая вертикальная цепочка:
1. **Config Layer**: `application.yml` (TTL токена, Cookie Max-Age).
2. **Security / Token Helper**: `JwtTokenProvider.java`, `JwtCookieHelper.java` (генерация, claims, cookie expiration).
3. **Client State / Persistence**: `authContext.tsx` (гидратация из `localStorage` при F5, обработка 401).
4. **UI Entry Point**: `EmailAuthForm.tsx` (флаг remember-me, checkbox).

Знание архитектурной вертикали позволяет сразу ограничиться **4 файлами** без единого лишнего поискового запроса.

## 2. Windows PowerShell: Ошибка оператора конкатенации `&&`

### Проблема
В Windows PowerShell 5.1 (стандартный шелл Windows 10/11 без установленного отдельного PowerShell Core 7+) оператор `&&` **не поддерживается**:
```powershell
git add . && git commit -m "..." && git push
# Ошибка парсера:
# The token '&&' is not a valid statement separator in this version.
```

### Правило для Windows окружения
Все составные команды в скриптах и вызовах агента должны использовать точку с запятой `;`:
```powershell
git add .; git commit -m "..."; git push
```

## 3. Scoped Prompting: Как сокращать сессии с 7 минут до 1.5 минут

### Размытый промпт (провоцирует 8 поисков и 29 файлов):
> *«Сделай так, чтобы после обновления страницы меня постоянно не кинуло в логин страницу, живет 7 дней, а подольше 30 дней»*

### Сфокусированный инженерный промпт (сокращает до 4 файлов):
> *«Настрой Remember-Me на 7/30 дней. Бэкенд: JwtCookieHelper и application.yml. Фронтенд: гидратация в features/auth/model/authContext и чекбокс в EmailAuthForm»*
