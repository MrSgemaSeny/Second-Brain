# Frontend Архитектура (FSD, dnd-kit, Zustand)

## Описание
Организация фронтенд-части проекта на базе React и Vite с использованием современных архитектурных подходов.

## Технические решения
- **Архитектура Feature-Sliced Design (FSD)**: 
  - Код строго разделен на слои: `app`, `pages`, `features`, `entities`, `shared`. Это облегчает масштабирование и навигацию по проекту.
- **State Management**:
  - **React Query**: Используется для серверного стейта, кеширования API-запросов и синхронизации данных.
  - **Zustand**: Применяется исключительно для локального стейта сложного визуального редактора резюме.
- **Визуальный редактор (Drag-and-Drop)**:
  - Реализован с помощью библиотеки `@dnd-kit/core` для сортировки и изменения порядка секций резюме.
  - **Важно для UX**: Требует явного подключения `TouchSensor` для поддержки тачскринов, иначе drag-and-drop ломается на мобильных устройствах.
  - Изменение видимости секций в редакторе только меняет флаг, не удаляя сами данные из БД.
