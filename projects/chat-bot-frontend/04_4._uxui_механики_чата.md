## 4. UX/UI Механики чата

Интерфейс чата содержит несколько специфических паттернов, требующих точечной работы с DOM (через `useRef`).

### 4.1 Auto-scroll to Bottom
Когда приходит новое сообщение, контейнер сообщений должен автоматически прокручиваться вниз, чтобы показать его.
- **Реализация:** Создается `<div ref={messagesEndRef} />` в самом низу списка сообщений. В `useEffect`, следящем за массивом `messages`, вызывается `messagesEndRef.current?.scrollIntoView({ behavior: 'smooth' })`.

### 4.2 Идентификация отправителя
Каждое входящее сообщение должно визуально отличаться в зависимости от того, чье оно.
- `if (message.senderId === currentUser.id)` -> Рендерим сообщение справа, с зеленым фоном (Класс `msg-bubble msg-own`).
- `else` -> Рендерим слева, с серым фоном.

### 4.3 Уведомления и Звук (Browser API)
При получении сообщения в свернутую вкладку, фронтенд использует Notification API браузера (`new Notification('New message')`) и проигрывает короткий звуковой сигнал.
