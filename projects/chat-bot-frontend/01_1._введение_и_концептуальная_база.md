## 1. Введение и концептуальная база

### 1.1 Что такое Chat Bot Frontend
Это Single Page Application (SPA), интерфейс пользователя для платформы обмена сообщениями. Если бэкенд отвечает за маршрутизацию и хранение, то фронтенд решает сложнейшие задачи управления состоянием в браузере, поддержания персистентного соединения и мгновенного обновления DOM при высоких нагрузках (шторм сообщений).

### 1.2 Роль Vite в экосистеме
Наличие `vite.config.js` — маркер перехода на современные тулчейны сборки. В отличие от Webpack (Create React App), который бандлит всё приложение при каждом изменении, Vite использует нативные ES-модули браузера для мгновенного HMR (Hot Module Replacement). Это ускоряет разработку в десятки раз.
