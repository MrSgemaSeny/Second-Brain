## 2. Технологический стек и сетевая архитектура

### 2.1 Ядро
- **Язык:** Java 11/17 (Long-Term Support).
- **Сборка:** Maven.
- **Сетевой протокол:** Скорее всего, используется чистый WebSocket (JSR 356) поверх TCP, либо фреймворк Netty (NIO - Non-blocking I/O) для обеспечения асинхронной неблокирующей работы с тысячами открытых TCP-соединений.

### 2.2 Проблема C10K и NIO
В классической Java (до Project Loom/Virtual Threads) создание отдельного потока (Thread) на каждое входящее соединение потребляло ~1 МБ оперативной памяти только на стек потока. При 10 000 онлайн-зрителях сервер упал бы от `OutOfMemoryError: unable to create new native thread`.
Использование NIO (Non-blocking I/O, селекторов каналов) позволяет одному потоку (Event Loop) обслуживать тысячи соединений одновременно, переключаясь между ними только тогда, когда в канале появляются байты для чтения.
