## 1. Введение и концепция проекта

### 1.1 Что такое Backend Damir
"Backend Damir" — это экспериментальная, но полнофункциональная распределенная система, написанная на Python. Она знаменует собой отход от Java/Spring-монолитов в сторону полиглотной микросервисной архитектуры, где Python используется там, где он исторически доминирует: быстрая работа с медиафайлами, прототипирование API через FastAPI и машинное обучение.

Проект логически разделен на два Bounded Contexts (Домена):
1. **test_cinema:** Ядро стриминговой платформы. Обработка видеофайлов, раздача медиа-контента клиентам, управление метаданными фильмов.
2. **Insight:** Модуль аналитики и Data Science. Генерация рекомендаций для пользователей на основе их истории просмотров и взаимодействия с контентом.

### 1.2 Целевая архитектура и мотивация
В современных кинотеатральных платформах (Netflix, Kinopoisk) бэкенд всегда разделен. Java/Go могут обрабатывать биллинг, подписки и авторизацию, но отдачу видео через HTTP Range Requests и работу с тензорами для ML эффективнее писать на Python. Проект "Backend Damir" — это реализация именно этой концептуальной части большой корпоративной системы.
