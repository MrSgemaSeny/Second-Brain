## 5. Интеграция с внешними системами

"Backend Damir" не работает в вакууме. Он спроектирован для интеграции с Java-бэкендом или напрямую с фронтендом.
- **RESTful API:** Взаимодействие происходит по JSON REST API. FastAPI генерирует OpenAPI спецификацию `/docs`, которую Java-разработчики используют для генерации Feign-клиентов.
- **CORS (Cross-Origin Resource Sharing):** Настроен `CORSMiddleware` для разрешения запросов с доменов фронтенда (React).
