## 2. Технологический стек и UI Архитектура 

### 2.1 Фронтенд-ядро
- **Язык программирования:** JavaScript (ECMAScript 2021+). В поздних версиях проекта (Valeur v2) планируется строгий переход на TypeScript.
- **Библиотека:** React 17/18.
- **Сборщик:** Webpack (стандарт для Create React App) или Vite (в более современных форках).

### 2.2 Архитектурная парадигма (FSD - Feature-Sliced Design)
Хотя Valeur — ранний проект, структура папок уже тяготеет к модульности FSD (разделение по фичам), что позже стало стандартом в проекте ZhanFinance.
**Слои (Layers):**
- **app/**: Настройка провайдеров (Router, Store, Theme).
- **pages/**: Страницы приложения (`JobsPage`, `CandidateDashboardPage`, `HrAnalyticsPage`).
- **widgets/**: Сложные блоки (`KanbanBoard`, `CvViewer`, `JobFilters`).
- **features/**: Бизнес-действия (`apply-for-job`, `move-candidate-stage`, `add-interview-feedback`).
- **entities/**: Сущности (`Job`, `Candidate`, `Company`).
- **shared/**: UI-кит (Кнопки, Инпуты, Select), API-конфиг.

### 2.3 State Management (Управление состоянием)
Управление воронкой найма требует сложного глобального состояния.
- Использовался **Redux Toolkit (RTK)** для хранения списка кандидатов.
- Перемещение карточки кандидата на доске вызывало `dispatch(updateCandidateStage({ id, newStage }))`, что оптимистично обновляло UI до ответа сервера.
