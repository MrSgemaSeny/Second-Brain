## 2. Технологический стек

### 2.1 Ядро
- **Язык:** Java 11/17.
- **Фреймворк:** Spring Boot 2.x / 3.x.
- **Сборщик:** Maven (`pom.xml`, `mvnw`). Наличие Maven Wrapper (`mvnw`) — хорошая практика, гарантирующая, что проект соберется на CI/CD сервере с нужной версией Maven.

### 2.2 Сетевые протоколы
- **STOMP (Simple Text Oriented Messaging Protocol):** Протокол поверх WebSocket. WebSocket передает просто "сырые" байты или текст. STOMP добавляет семантику: маршрутизацию (destinations), подписки (subscribe), сообщения (send) — превращая WebSocket в полноценный брокер сообщений внутри браузера.
- **SockJS:** Fallback-библиотека. Если корпоративный файрвол клиента блокирует WebSocket, SockJS незаметно деградирует соединение до XHR Streaming или Long Polling, сохраняя работу чата.

### 2.3 Безопасность и Данные
- **Spring Security + JWT:** Токены используются для аутентификации REST-запросов и при Handshake-этапе WebSocket соединения.
- **Spring Data JPA (Hibernate):** ORM для сохранения пользователей, комнат чата и истории сообщений в реляционную базу данных.
