## 2. Технологический стек

### 2.1 Ядро (Backend)
- **Язык программирования:** Java SE 11.
- **API Wrapper:** `org.telegram.telegrambots` (TelegramBots API).
- **Паттерн взаимодействия:** Long Polling. Приложение держит постоянное HTTP-соединение с серверами Telegram и получает обновления пакетами (batches).

### 2.2 База данных (Persistence Layer)
- **СУБД:** PostgreSQL 12+.
- **Драйвер:** Raw JDBC (`java.sql.*`).
- **Пул соединений:** HikariCP (или базовый `DriverManager`, если проект был на самых ранних стадиях). Использование `PreparedStatement` для защиты от SQL-инъекций.
