## 2. Технологический стек

Проект разделен на два изолированных микросервиса, общающихся через WebSockets.

### 2.1 Бэкенд (ML & Networking)
- **Язык:** Python 3.10+ — стандарт де-факто для машинного обучения.
- **Фреймворк:** FastAPI. Используется исключительно для инициализации WebSocket-сервера и (при необходимости) раздачи статических файлов. FastAPI базируется на ASGI (Starlette), что делает его идеальным для асинхронного I/O.
- **Сервер:** Uvicorn — молниеносный ASGI-сервер на базе uvloop.
- **Computer Vision:** Google MediaPipe (модуль `solutions.hands`). Выбор обусловлен тем, что модель работает на CPU с минимальными задержками и не требует наличия VRAM, что критично для ноутбука с RTX 3050 (4GB), который лучше поберечь для других задач. OpenCV (`cv2`) используется для конвертации массивов и базовой обработки изображений.

### 2.2 Фронтенд (UI & Capture)
- **Ядро:** React 19, TypeScript, Vite.
- **Стилизация:** Tailwind CSS v4. Отказ от конфигурационных файлов в пользу плагина Vite.
- **Медиа API:** `navigator.mediaDevices.getUserMedia` для доступа к камере. HTML5 Canvas API (2D Context) для рендеринга.
