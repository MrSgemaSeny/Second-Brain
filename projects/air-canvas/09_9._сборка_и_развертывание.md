## 9. Сборка и развертывание

### 9.1 Локальная разработка
1. **Python (Backend):**
   ```bash
   cd backend
   python -m venv venv
   source venv/bin/activate # или venv\Scripts\activate
   pip install fastapi uvicorn mediapipe opencv-python websockets
   uvicorn main:app --reload --port 8000
   ```
2. **React (Frontend):**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

### 9.2 Будущий деплой
Для продакшена потребуется SSL (HTTPS). WebSockets должны работать по протоколу WSS, а `getUserMedia` в браузере работает только в безопасном контексте (HTTPS или localhost). Деплой Python бэкенда на Fly.io, а фронтенда на Vercel или GitHub Pages.
