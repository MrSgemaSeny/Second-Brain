## 2. Технологический стек

### 2.1 Ядро и Фреймворк
- **Язык:** Python 3.9+. Выбран за нативную поддержку `async/await`.
- **Фреймворк:** `aiogram 2.x` или `aiogram 3.x`. Это полностью асинхронный фреймворк, предоставляющий мощную систему фильтров, Middlewares (промежуточного ПО) и FSM (конечных автоматов).

### 2.2 Хранение данных (Database)
- **СУБД:** SQLite 3 (`football_bot.db`).
- **ORM:** `SQLAlchemy` (или `Tortoise ORM` / `Aiosqlite` для асинхронной работы).
- **Почему SQLite?** Для ботов, обслуживающих один чат или небольшое комьюнити (до 10 000 пользователей), SQLite — идеальный выбор. Данные хранятся в одном файле на диске, нет сетевой задержки (Network Latency) при обращении к БД, не нужен Docker с PostgreSQL.
