## Реальные минусы и причины смерти проекта

Несмотря на полезный опыт, код этого проекта ужасен по современным стандартам. Почему он умер:
- Глобальный лок базы данных (SQLite Database is Locked). Бот не мог обрабатывать более 2-х транзакций одновременно.
- Отсутствие нормального логирования.
- Нечитаемый код обработчиков (handlers) без разбиения на сервисы.
