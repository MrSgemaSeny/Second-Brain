# 1. Введение и обзор MrDevCourses

### 1.1 Что это такое
MrDevCourses — обучающая платформа (LMS) для бренда Mr Developer.
Студент регистрируется через Google OAuth2, получает доступ к курсу и проходит его по одному уроку в день.
Ключевая механика: **drip-контент** — урок N доступен только если прошло `N-1` дней с момента записи на курс (`enrolled_at`).
Студент физически не может ускорить прохождение — это защита от поверхностного изучения без закрепления на практике.

### 1.2 Основные возможности
- Google OAuth2 — беспарольный вход в один клик.
- Каталог курсов (активные и запланированные курсы).
- Drip-доступ к урокам: один день — один урок строго по дате записи.
- Плеер уроков: YouTube embed + структурированный конспект.
- Личный кабинет: текущий прогресс, открытые и заблокированные дни, дата следующего unlock.
- Админ-панель: управление курсами/уроками, ручная запись и мониторинг студентов.

### 1.3 Целевая аудитория и масштаб
Студенты Mr Developer (вайбкодинг, разработка с нуля, менторство). Масштаб MVP: 2-5 студентов. Целевой горизонт: 50-200.
