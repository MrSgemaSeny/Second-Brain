# MrDevCourses — Полный Роадмап
> Горизонт: пилот с 2 студентами → полноценный запуск потока
> Принцип: сначала удобство студента и автоматизация твоей нагрузки, потом масштаб

---

## Текущее состояние (август 2026)

- 2 живых студента, менторство через Discord
- Платформа: Auth, Courses, Drip-engine, RAG-тьютор, AI-грейдер, квизы, сертификаты — готовы
- Human homework pipeline (V16) — только что закрыт
- Уроки 1-3 с материалами — есть
- Бренд Mr Developer — сформирован, визуал готов

---

## Фаза 0 — Операционная основа
> Цель: 2 текущих студента работают полностью через сайт, Discord только для созвонов
> Срок: 1-2 недели

### Платформа

**Урок как операционная карточка**
- Каждый урок содержит не только текст, но и: прямые ссылки на все инструменты, скачиваемые файлы (системный промпт, шаблоны), чеклист установки по шагам
- Студент не ищет ничего в Discord — всё на странице урока

**Кнопка "Не получается"**
- На каждом шаге урока и в каждом задании
- Форма: выбор шага из списка + свободный текст
- Результат: Telegram-уведомление тебе с именем студента, уроком, шагом и описанием проблемы

**Telegram-бот (твой dashboard)**
- Уведомления о событиях:
  - Студент сдал ДЗ (имя + ссылки)
  - Студент нажал "Не получается" (имя + урок + шаг)
  - Студент не заходил 3+ дней
  - Новая регистрация
- Команды:
  - `/approve <id>` — принять ДЗ, студент получает уведомление
  - `/reject <id> <комментарий>` — вернуть на доработку
  - `/status` — кто где сейчас
  - `/stuck` — кто не заходил 3+ дней
  - `/hw` — очередь непроверенных домашек

**Dashboard студента**
- Один экран: текущий урок, следующий шаг, прогресс-бар, статус ДЗ
- Следующий урок — когда откроется (countdown или дата)
- Никакой навигации в поисках "что дальше"

### Контент

- Урок 1-3: встроить все ссылки и файлы прямо в карточки уроков на платформе
- Чеклист установки инструментов (VS Code, Antigravity, Claude Desktop, Cursor) — пошагово с скриншотами

## Фаза 1 — Пилот закрыт, готов к следующему потоку
> Цель: первые 2 студента дошли до финала, система работает без ручного контроля
> Срок: 3-4 недели от старта Фазы 0

### Платформа

**Stuck Detection (автоматический)**
- Cron: если студент не открывал урок 3 дня → автоматическое сообщение студенту на платформе + уведомление тебе в TG
- Сообщение студенту: "Застрял? Нажми кнопку — ментор поможет. Или спроси AI-тьютора."

**Уведомления студенту**
- ДЗ проверено → уведомление на платформе + (опционально) email
- Новый урок открылся → уведомление
- Фидбек от ментора → уведомление с текстом

**Онбординг-поток**
- После регистрации: автоматическое приветственное сообщение на платформе
- Инструкция: как работает курс, как сдавать ДЗ, как обращаться к ментору
- Ссылка на Discord для созвонов

**Публичная стена проектов**
- Страница `/projects` — галерея финальных проектов выпускников
- Имя студента, название проекта, ссылка на живой сайт
- Это и мотивация для текущих студентов, и социальное доказательство для новых

### Контент

- Урок 4: что такое баг и как его убивать (читать ошибки консоли, error loop промпт)
- Урок 5: сквозной проект — добавляем форму обратной связи к лендингу
- Финальный урок: деплой финального проекта + "что дальше" карта

### Метрики пилота (собрать данные)
- Где студенты нажимали "Не получается" чаще всего
- На каком уроке/шаге было больше всего вопросов
- Сколько дней в среднем между уроками
- Что студенты писали в поле "комментарий" при сдаче ДЗ

Эти данные определяют приоритеты Фазы 2.

## Фаза 2 — Масштаб: первый поток
> Цель: 10-20 студентов одновременно, ты не тонешь в ручной работе
> Срок: после завершения пилота

### Платформа

**RAG-тьютор как первая линия поддержки**
- Кнопка "Не получается" → сначала показывает релевантные ответы из базы знаний
- Если не помогло → отправляет тебе
- База знаний: FAQ по инструментам, типичные ошибки установки, частые вопросы по урокам
- Это снимает ~60% бытовых вопросов до того как они доходят до тебя

**Асинхронный Q&A**
- Студент задаёт вопрос текстом прямо на платформе (не в Discord)
- Ты отвечаешь текстом через панель ментора
- История вопросов и ответов видна студенту
- Хорошие ответы → пополняют базу знаний RAG-тьютора

**Реферальная система**
- Выпускник получает реферальную ссылку
- Привёл друга → скидка на следующий курс или бонус
- Для 16-25 лет работает через Telegram и сторис

**Групповой прогресс (опционально)**
- Студенты видят анонимный прогресс потока: "68% студентов уже на уроке 3"
- Создаёт социальное давление в хорошем смысле — не хочется отставать

### Контент

- Полная программа: минимум 7 уроков со сквозным проектом
- Каждый урок: теория + инструменты + практика + ДЗ + типичные ошибки
- FAQ по каждому уроку на основе реальных вопросов из пилота

### Операционное

- Чёткое расписание потока: даты старта, длительность, когда открываются уроки
- Лендинг курса обновлён: проекты выпускников пилота, отзывы, результат
- Форма записи на следующий поток (waitlist или прямая регистрация)

## Фаза 3 — Продукт живёт сам
> Цель: студент проходит 80% пути без твоего участия, ты вмешиваешься только там где действительно нужен
> Срок: долгосрочно, после нескольких потоков

### Платформа

**Полноценный AI-тьютор**
- RAG по всей базе знаний курса
- Понимает контекст: какой урок студент проходит, что уже сдал, где застрял
- Первая линия для любого вопроса

**Аналитика для ментора**
- Воронка: сколько студентов на каждом уроке
- Где самый высокий отвал
- Какие ДЗ возвращаются на доработку чаще всего
- Время между регистрацией и первым ДЗ

**Монетизация**
- Платный следующий курс (более глубокий уровень)
- Или платный индивидуальный менторинг поверх бесплатного курса

### Контент

- Второй курс: для тех кто хочет глубже после вайбкодинга
- Библиотека: записанные ответы на частые вопросы (короткие видео или текст)

## Что никогда не автоматизируется

| Всегда живой ментор | Система справляется |
|---|---|
| Первый созвон с новым студентом | Открытие уроков по расписанию |
| Студент потерял мотивацию | Уведомления о прогрессе |
| Архитектурный вопрос по проекту студента | Приём и статус ДЗ |
| Студент застрял и не может сформулировать проблему | FAQ через RAG-тьютора |
| Финальный созвон — разбор проекта | Выдача сертификата |

Фаза 3:  Студент проходит 80% пути без тебя, NPS > 8
