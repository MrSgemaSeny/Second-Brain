## 4. Модули системы (Детальный разбор)

### 4.1 Auth Module (Авторизация)
- **Функционал**: Регистрация, логин, обновление сессии, logout.
- **Особенности**: Выдача Access Token (JWT, 24 часа) и Refresh Token (Redis, 30 дней). Логин возможен как через Email/Pass, так и через GitHub OAuth. При регистрации автоматически создается пустая запись в `profiles`.

### 4.2 Profile Module (Профиль и сущности)
- **Функционал**: CRUD-операции над профилем и его секциями (опыт, навыки, проекты).
- **Особенности**: Безопасность на уровне строк (Row-Level Security) реализована через проверки в сервисах: каждый запрос обновляет данные только для `SecurityUtils.getCurrentUserId()`. Наличие эндпоинта `reorder` для сохранения порядка секций, настроенного в drag-and-drop редакторе.

### 4.3 GitHub Module (Интеграция)
- **Функционал**: Запрос данных у GitHub API по OAuth токену пользователя.
- **Особенности**: Парсинг языков из всех репозиториев и формирование статистики. Кэширование ответов от GitHub в Redis на 1 час (чтобы не исчерпать Rate Limit в 5000 запросов/час).

### 4.4 Resume Module (Генерация и парсинг)
- **Функционал**: Превращение профиля в PDF и загрузка старого PDF в систему.
- **Особенности**: Для генерации PDF используется Thymeleaf. Профиль "впрыскивается" в HTML-шаблон (например, `classic.html`), затем Flying Saucer рендерит его в байтовый массив PDF. Ограничение для Free-пользователей проверяется через счетчики в Redis (`resume:gen:userId:date`).

### 4.5 Portfolio Module (Публичная визитка)
- **Функционал**: Выдача данных для страницы `medev.app/{username}`.
- **Особенности**: Это единственный полностью открытый эндпоинт (без JWT). Возвращает агрегированный DTO. Если профиль отмечен как `is_public = false`, API возвращает 404, не раскрывая существование пользователя.

### 4.6 Billing Module (Монетизация)
- **Функционал**: Обработка подписок и интеграция со Stripe.
- **Особенности**: Генерация ссылок на оплату (`CheckoutSession`), обработка вебхуков от Stripe (`checkout.session.completed`, `customer.subscription.deleted`) для выдачи или отзыва Pro-статуса.
