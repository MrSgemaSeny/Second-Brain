## 6. MVP — Roadmap (Фазы реализации)

### Фаза 1 — Инициализация
- [x] Создание структуры репозитория (монорепо frontend + backend).
- [x] Инициализация Spring Boot и React Vite.
- [x] Написание базовой документации.

### Фаза 2 — MVP Core (Критический путь)
- [ ] Разработка базового Auth (JWT, логин/регистрация).
- [ ] Flyway миграции (V1-V8).
- [ ] CRUD операции для профиля.
- [ ] Интеграция парсинга GitHub.
- [ ] Первый HTML-шаблон для PDF и его генерация.
- [ ] Выкатка на GitHub Pages (Front) и Fly.io (Back).

### Фаза 3 — Расширение (Вторая итерация)
- [ ] Имплементация `/v1/auth/refresh` (инвалидация токенов, Redis логика).
- [ ] Поддержка нескольких сессий (refresh token на каждое устройство `refresh:{userId}:{deviceId}`).
- [ ] Парсинг чужого резюме (извлечение текста через PDFBox).
- [ ] Реализация Drag-and-Drop редактора секций на React (dnd-kit).
- [ ] Создание дополнительных шаблонов резюме (Modern, Minimal).
- [ ] Поддержка уровней владения языками.
- [ ] Мультиязычность интерфейса (i18n).

### Фаза 4 — Биллинг
- [ ] Stripe API, генерация Checkout сессий.
- [ ] Интеграция Kaspi Pay.
- [ ] Механизм блокировки Pro-фич через `@Component PlanGuard`.

### Фаза 5 — Качество
- [ ] Глобальный аудит безопасности эндпоинтов.
- [ ] Настройка Sentry для трекинга ошибок фронта и бэка.
- [ ] Unit и Integration тесты.
