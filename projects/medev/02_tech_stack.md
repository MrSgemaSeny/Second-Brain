## 2. Технологический стек

### 2.1 Бэкенд (Java/Spring Boot)
- **Язык и фреймворк**: Java 17, Spring Boot 3.3.0. Выбор обоснован надежностью и готовностью к production.
- **База данных**: PostgreSQL. Надежная реляционная БД для хранения структурированных профилей.
- **Миграции**: Flyway. Строгий контроль схемы БД (8 базовых таблиц создаются через `V1`-`V8` скрипты).
- **Кэширование**: Redis. Используется для хранения refresh-токенов, кэширования ответов от GitHub API (чтобы не упираться в лимиты) и хранения временных стейтов.
- **Безопасность**: Spring Security, JWT (access/refresh токены).
- **PDF-генерация**: Thymeleaf (шаблонизация) + Flying Saucer (HTML to PDF) + PDFBox (для парсинга входящих файлов).

### 2.2 Фронтенд (React/Vite)
- **База**: React 19, TypeScript, Vite. Обеспечивают максимальную скорость разработки и строгую типизацию.
- **Архитектура**: Feature-Sliced Design (FSD). Разделение на layers (app, pages, features, entities, shared).
- **Стейт-менеджмент**: React Query (для серверного стейта и кэширования API-запросов) + Zustand (для локального стейта сложного drag-and-drop редактора).
- **Стилизация**: Tailwind CSS v4. Быстрая компонентная стилизация.
- **Интерактив**: `@dnd-kit/core` для реализации drag-and-drop сортировки секций в редакторе резюме.

### 2.3 Инфраструктура и деплой
- **Backend Deployment**: Fly.io (контейнеризация, авто-SSL).
- **Frontend Deployment**: GitHub Pages.
- **CI/CD**: GitHub Actions. Автоматический прогон тестов (`./gradlew test`) и автодеплой на Fly.io при слиянии в ветку `main`.
- **Платежи**: Stripe API + вебхуки.
