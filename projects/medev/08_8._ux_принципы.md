## 8. UX Принципы

1. **Zero friction onboarding**: Регистрация через GitHub должна моментально создавать базовый профиль, готовый к просмотру.
2. **Real-time preview**: Любое изменение в редакторе (добавление навыка, скрытие опыта) должно мгновенно отображаться в превью резюме (внутри iframe).
3. **Сохранность данных**: Скрытие секции в резюме — это только изменение флага видимости, удалять данные из БД нельзя.
