## 6. MVP — Roadmap (Фазы реализации)

### Фаза 1 — Инициализация
- [x] Создание структуры репозитория (монорепо frontend + backend).
- [x] Инициализация Spring Boot и React Vite.
- [x] Написание базовой документации.

### Фаза 2 — MVP Core (Критический путь)
- [x] Разработка базового Auth (JWT, логин/регистрация).
- [x] Flyway миграции (V1-V11).
- [x] CRUD операции для профиля.
- [x] Интеграция парсинга GitHub (OAuth2).
- [x] Первый HTML-шаблон для PDF и его генерация.
- [ ] Выкатка на GitHub Pages (Front) и Fly.io (Back).

### Фаза 3 — Расширение (Вторая итерация)
- [x] Имплементация `/v1/auth/refresh` (инвалидация токенов, Redis логика).
- [x] Поддержка нескольких сессий (refresh token на каждое устройство `refresh:{userId}:{deviceId}`).
- [x] Парсинг чужого резюме (извлечение текста через PDFBox).
- [x] Реализация Drag-and-Drop редактора секций на React (dnd-kit).
- [x] ИИ-ассистент: стриминг (SSE) ответов от Groq API.
- [x] Автоматическая генерация текста в редакторе с помощью ИИ.
- [ ] Создание дополнительных шаблонов резюме (Modern, Minimal).
- [ ] Поддержка уровней владения языками.
- [x] Мультиязычность интерфейса (i18n).

### Фаза 4 — Биллинг
- [x] Stripe API, генерация Checkout сессий.
- [x] Интеграция Kaspi Pay (пока отложено, сделан Stripe).
- [x] Механизм блокировки Pro-фич через `@Component PlanGuard`.

### Фаза 5 — Качество
- [x] Глобальный аудит безопасности эндпоинтов (Аудиты 1 и 2 закрыты).
- [ ] Настройка Sentry для трекинга ошибок фронта и бэка.
- [x] Unit и Integration тесты (AuthService, StripeService, Zustand).
