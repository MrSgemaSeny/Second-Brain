## 1. Введение и обзор проекта

### 1.1 Что это такое
MeDev — это data-first платформа для разработчиков. 
Основная проблема текущих инструментов: разработчики тратят часы на поддержание своего резюме (в Word, Canva или кривых генераторах), отдельного сайта-портфолио и профиля на GitHub. Все эти ресурсы не синхронизированы, и данные приходится дублировать.
MeDev решает эту проблему созданием единого, централизованного профиля (Single Source of Truth). Разработчик один раз загружает свои данные (или платформа парсит их из GitHub/старого PDF-резюме), после чего может автоматически генерировать красивые PDF-резюме, делиться ссылкой на стильное веб-портфолио и выгружать README для GitHub.

### 1.2 Основные возможности (Киллер-фичи)
- **Data-First подход**: Данные хранятся абстрактно от представления. Один профиль → множество форматов вывода.
- **Интеграция с GitHub**: Автоматическое подтягивание репозиториев, статистики активности (коммиты, pull requests) и используемых языков программирования через GitHub API.
- **Интеллектуальный парсинг резюме**: Загрузка старого PDF-резюме и извлечение из него текста с последующим маппингом в структурированный профиль (с помощью Apache Tika/PDFBox).
- **Продвинутый конструктор резюме**: Визуальный drag-and-drop редактор секций (построенный на `dnd-kit`). Пользователь решает, какие блоки показывать, а какие скрывать, не удаляя данные.
- **Публичное веб-портфолио**: Готовая стильная страница вида `medev.app/username`, которая адаптирована под мобильные устройства и служит заменой личному сайту-визитке.
- **Экспорт PDF**: Генерация резюме на основе HTML/CSS-шаблонов с рендерингом на сервере (Thymeleaf + Flying Saucer).

### 1.3 Целевая аудитория и монетизация
- **Аудитория**: Разработчики уровней Junior, Middle, Senior. Студенты, ищущие первую работу. На старте — рынок СНГ, затем — глобальный рынок.
- **Монетизация (Freemium)**: 
  - **Free**: 3 генерации резюме в день, 1 шаблон, лого MeDev на странице, ватермарк на PDF.
  - **Pro**: Безлимитные генерации, все шаблоны, кастомные секции, экспорт GitHub README, отсутствие ватермарков. Платная подписка (Stripe для мира, Kaspi Pay для СНГ).
