## 5. Ролевая модель и безопасность

### 5.1 Роли
- **USER**: Обычный разработчик. Может редактировать только свой профиль.
- **ADMIN**: Администратор системы. Имеет доступ к статистике, управлению пользователями и шаблонами резюме.

### 5.2 Защита данных
- **IDOR Protection**: Все эндпоинты профиля (`/v1/profile/**`) не принимают `userId` из параметров URL. Вместо этого он извлекается строго из проверенного JWT-токена в бэкенде.
- **Скрытые исключения**: Наличие `GlobalExceptionHandler`. Система не отдает сырые StackTrace на клиент. Все ошибки маппятся в стандартизированный JSON (`code`, `message`).
- **Секреты**: Токены GitHub хранятся в зашифрованном виде в БД. Все ключи API (Stripe, JWT Secret) лежат строго в переменных окружения.
