## 6. Интеграция LLM и AI-Аналитика 

"Склад" — это AI-First продукт. Для этого разворачивается отдельный Python микросервис.

### 6.1 Text-to-SQL (Чат с базой данных)
Менеджер может спросить: *"Покажи товары на складе Альфа, оборачиваемость которых меньше 10 дней"*.
- **Поток:** React -> Gateway -> AI Service (Python/FastAPI).
- **Логика:** LLM получает схему БД (без данных) и генерирует SQL-запрос.
- **Безопасность:** Сгенерированный SQL прогоняется через жесткий парсер (запрет DROP/UPDATE/INSERT) и выполняется под Read-Only ролью PostgreSQL в рамках конкретной схемы тенанта.

### 6.2 Автоматизация приемки (Vision API)
Кладовщик фотографирует инвойс поставщика.
- Vision LLM извлекает табличные данные (артикулы, количества).
- С помощью векторного поиска (FAISS/Pinecone) нечеткие наименования из инвойса ("Вода негазир. 0.5") маппятся на эталонный справочник номенклатуры системы ("Вода Tassay 0.5л Негазированная").
