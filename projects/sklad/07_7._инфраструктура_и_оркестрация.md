## 7. Инфраструктура и оркестрация 

### 7.1 Kubernetes (K8s)
- Проект с самого начала пакуется в Helm-чарты.
- **Service Mesh:** Istio для mTLS шифрования между микросервисами, Canary Deployments и Circuit Breaking.
- **Ingress:** NGINX Ingress Controller.

### 7.2 CI/CD (GitOps)
- Сборка Docker-образов через GitHub Actions.
- Деплой через ArgoCD. ArgoCD следит за отдельным репозиторием с манифестами и автоматически синхронизирует состояние кластера с Git (Single Source of Truth).
