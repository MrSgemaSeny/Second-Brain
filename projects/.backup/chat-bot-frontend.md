### 3.2 Р–РёР·РЅРµРЅРЅС‹Р№ С†РёРєР» WebSocket СЃРѕРµРґРёРЅРµРЅРёСЏ
РџРѕРґРєР»СЋС‡РµРЅРёРµ Рє СЃРѕРєРµС‚Сѓ вЂ” СЌС‚Рѕ СЃР°Р№Рґ-СЌС„С„РµРєС‚. РћРЅ РёРЅРёС†РёР°Р»РёР·РёСЂСѓРµС‚СЃСЏ РІ `useEffect`.

## 🔴 Реальные минусы и причины смерти проекта

Несмотря на полезный опыт, код этого проекта ужасен по современным стандартам. Почему он умер:
- Memory Leaks при переходе между страницами (не отписывались от сокетов в useEffect cleanup).
- Фризы браузера из-за отсутствия Virtualization списка сообщений.
- Грязная мутация стейта (Direct state mutation).
