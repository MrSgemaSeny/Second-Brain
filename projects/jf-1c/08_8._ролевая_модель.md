## 8. Ролевая модель

### 8.1 Роли системы

Система определяет 6 ролей с различными правами доступа:

**ADMIN** — администратор системы. Полный доступ ко всем модулям и функциям. Может управлять пользователями, пайплайнами, настраивать систему, просматривать все данные. Типичное использование: владелец бизнеса, технический администратор.

**EMPLOYEE** — сотрудник компании. Доступ к назначенным задачам, клиентам и чатам. Может брать задачи из Task Pool, создавать подзадачи и комментарии. Типичное использование: бухгалтер, консультант.

**ADVISOR** — расширенный сотрудник. Полный доступ ко всем задачам и клиентам компании (сквозной доступ). Может просматривать аналитику, переназначать задачи. Типичное использование: старший консультант, руководитель группы.

**CLIENT** — клиент компании. Строго ограниченный доступ: видит только свои задачи, документы и счета. Не видит внутренних комментариев и чужих данных. Типичное использование: представитель компании-клиента.

**LEARNER** — ученик LMS-платформы. Доступ к купленным курсам и урокам. Может проходить обучение и получать сертификаты. Типичное использование: студент, новый сотрудник на обучении.

**CURATOR** — куратор курсов. Доступ к проверке заданий учеников и отслеживанию прогресса. Типичное использование: преподаватель, ментор.

### 8.2 Регистрация и модерация

Новые сотрудники проходят регистрацию со статусом PENDING. Администратор проверяет заявку и утверждает (APPROVED) или отклоняет (REJECTED). Только APPROVED пользователи могут входить в систему. Это предотвращает создание фейковых аккаунтов.

### 8.4 ADVISOR — особая роль

Роль ADVISOR заслуживает отдельного внимания. В типичной CRM бухгалтерской компании старший консультант должен видеть все процессы по всем клиентам для экспертного контроля. CrmAccessService реализует "穿透访问" (сквозной доступ) для ADVISOR — проверка владения задачей отключается, и запрос пропускается, если пользователь имеет роль ADVISOR.

```java
public boolean canAccessTask(Long userId, Task task) {
  if (hasRole(userId, Role.ADMIN)) return true;
  if (hasRole(userId, Role.ADVISOR)) return true; // Сквозной доступ
  
  // Для остальных — проверка владения
  return task.getAssignedUserId().equals(userId) 
      || task.getCreatedByUserId().equals(userId);
}
```
