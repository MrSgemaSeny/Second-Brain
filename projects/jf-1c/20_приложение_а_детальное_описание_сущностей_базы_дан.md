## Приложение А: Детальное описание сущностей базы данных

### А.1 Таблица app_users

Основная таблица пользователей системы. Структура:

| Колонка | Тип | Описание |
|---------|-----|----------|
| id | BIGSERIAL | Первичный ключ |
| email | VARCHAR(255) | Уникальный email |
| password_hash | VARCHAR(255) | Bcrypt-хеш пароля |
| first_name | VARCHAR(100) | Имя |
| last_name | VARCHAR(100) | Фамилия |
| phone | VARCHAR(50) | Телефон |
| role | VARCHAR(50) | Роль (ADMIN, EMPLOYEE, CLIENT, etc.) |
| registration_status | VARCHAR(50) | PENDING, APPROVED, REJECTED |
| enabled | BOOLEAN | Активен ли аккаунт |
| totp_secret | VARCHAR(255) | Секрет TOTP (nullable) |
| two_factor_enabled | BOOLEAN | Включена ли 2FA |
| google_id | VARCHAR(255) | Google OAuth ID (nullable) |
| created_at | TIMESTAMP | Дата создания |
| updated_at | TIMESTAMP | Дата обновления |

Индексы: UNIQUE INDEX на email, INDEX на role, INDEX на registration_status.

### А.2 Таблица tasks

Задачи CRM-системы. Структура:

| Колонка | Тип | Описание |
|---------|-----|----------|
| id | BIGSERIAL | Первичный ключ |
| title | VARCHAR(500) | Заголовок задачи |
| description | TEXT | Описание (nullable) |
| client_id | BIGINT | FK на clients (nullable) |
| assigned_user_id | BIGINT | FK на app_users (nullable) |
| created_by_user_id | BIGINT | FK на app_users |
| stage_id | BIGINT | FK на stages |
| priority | VARCHAR(50) | LOW, MEDIUM, HIGH, URGENT |
| due_date | DATE | Дедлайн (nullable) |
| completed_at | TIMESTAMP | Дата завершения (nullable) |
| position | INTEGER | Позиция в стадии для сортировки |
| labels | TEXT[] | Массив меток (PostgreSQL array) |
| created_at | TIMESTAMP | Дата создания |
| updated_at | TIMESTAMP | Дата обновления |

Индексы: INDEX на client_id, INDEX на assigned_user_id, INDEX на stage_id, INDEX на priority, INDEX на due_date.
