## Приложение В: Диаграммы последовательности

### В.1 Последовательность аутентификации с 2FA

```
┌─────┐          ┌──────────┐         ┌─────────────┐         ┌──────────┐
│Client│          │Frontend  │         │AuthController│        │AuthService│
└──┬──┘          └────┬─────┘         └──────┬──────┘         └────┬─────┘
   │                  │                      │                      │
   │ POST /auth/login │                      │                      │
   │ email, password  │                      │                      │
   │─────────────────>│                      │                      │
   │                  │ POST /api/v1/auth/login│                      │
   │                  │──────────────────────>│                      │
   │                  │                      │ validate credentials │
   │                  │                      │──────────────────────>│
   │                  │                      │                      │
   │                  │                      │ 2FA enabled?         │
   │                  │                      │──────────────────────>│
   │                  │                      │                      │
   │                  │                      │ PreAuth token        │
   │                  │                      │<──────────────────────│
   │                  │ { requires2FA: true, │
   │                  │   preAuthToken }     │                      │
   │<─────────────────│                      │                      │
   │                  │                      │                      │
   │ User enters TOTP │                      │                      │
   │                  │                      │                      │
   │ POST /2fa/verify │                      │                      │
   │ preAuthToken,code│                      │                      │
   │─────────────────>│                      │                      │
   │                  │ POST /api/v1/2fa/verify│                     │
   │                  │──────────────────────>│                      │
   │                  │                      │ verify TOTP         │
   │                  │                      │──────────────────────>│
   │                  │                      │                      │
   │                  │                      │ { accessToken,       │
   │                  │                      │   refreshToken }     │
   │                  │                      │<──────────────────────│
   │                  │ { success: true,     │                      │
   │                  │   accessToken }      │                      │
   │<─────────────────│                      │                      │
   │                  │                      │                      │
```
