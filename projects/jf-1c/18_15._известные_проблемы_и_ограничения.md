## 15. Известные проблемы и ограничения

### 15.1 Открытые issues

| Issue | Статус | Комментарий |
|-------|--------|-------------|
| CF-Connecting-IP доверяется до Cloudflare | Known | Закроется при подключении Cloudflare |
| Refresh token race condition | Known (partial fix) | В http.ts есть refreshPromise-дедупликатор, предотвращающий параллельные refresh-запросы. Но при burst 401 ошибок возможны edge cases. |
| Caffeine cache без recordStats() | Known | WARN в логах, не влияет на работу |

### 15.2 Технический долг

**CRM Access Service** — изоляция реализована программно, не на уровне СУБД (Row Level Security). Это работоспособно, но менее надёжно при сложных запросах.

**Task Pool Performance** — при большом количестве задач в пуле может потребоваться виртуализация или пагинация.

**Frontend Bundle Size** —，随着 развитии проекта bundle может расти. Рекомендуется code splitting и lazy loading для редко используемых фич.

### 15.3 Out of Scope (не в планах)

- Интеграция с 1С (Epic-13) — требует отдельного проекта
- Push-уведомления (мобильные) — только email и Telegram
- Мультитенантность — несколько компаний в одном инстансе
- GraphQL API — REST достаточно для текущих потребностей
