## 10. Развертывание и инфраструктура

### 10.1 Хостинг

Бэкенд развёрнут на Fly.io — платформе для запуска контейнерных приложений. Преимущества Fly.io: автоматическое масштабирование, edge-распределение, простое управление через flyctl CLI, встроенная поддержка PostgreSQL.

Регион развёртывания: Amsterdam (eu-west). Для production рекомендуется регион, ближайший к целевой аудитории — Казахстан (Центральная Азия). В будущем планируется multi-region deployment.

Фронтенд развёрнут на GitHub Pages — бесплатном хостинге для статических сайтов. Каждый push в main автоматически деплоит обновлённую версию. Для SPA настроен fallback на index.html для всех маршрутов.

### 10.2 Docker

Бэкенд упакован в Docker-контейнер через Dockerfile в корне проекта. Multi-stage build минимизирует размер образа:
1. Build stage — компиляция Java, установка зависимостей
2. Runtime stage — минимальный образ с JRE

```dockerfile
FROM eclipse-temurin:17-jdk-alpine AS build
WORKDIR /app
COPY . .
RUN ./gradlew bootJar

FROM eclipse-temurin:17-jre-alpine
WORKDIR /app
COPY --from=build /app/build/libs/*.jar app.jar
ENTRYPOINT ["java", "-jar", "app.jar"]
```

### 10.3 CI/CD пайплайны

GitHub Actions автоматизирует процессы сборки, тестирования и деплоя.

**Frontend Pipeline (.github/workflows/ci.yml)**
- Триггер: push в main
- Шаги: checkout, setup Node.js, npm install, npm run build, deploy to GitHub Pages
- Fail-fast: тесты блокируют деплой

**Backend Pipeline (.github/workflows/deploy-backend.yml)**
- Триггер: изменения в zhan-finance-backend/**
- Шаги: checkout, setup Java, ./gradlew test, build Docker image, push to Fly.io, deploy

**Database Backup Pipeline (.github/workflows/db-backup.yml)**
- Триггер: ежедневно ночью
- Шаги: pg_dump, upload to artifacts, send Telegram notification

### 10.4 Переменные окружения

Критичные переменные хранятся в GitHub Secrets и Fly.io secrets:
- SPRING_DATASOURCE_URL — JDBC URL базы данных
- SPRING_DATASOURCE_USERNAME/PASSWORD — credentials БД
- JWT_SECRET — секретный ключ для подписи JWT
- SMTP credentials — для отправки email
- TELEGRAM_BOT_TOKEN — для уведомлений
- GOOGLE_CLIENT_ID/SECRET — для OAuth2

Никогда не хардкодить секреты в исходном коде!

### 10.6 Домен и CDN

Текущий домен: zhanfinance.fly.dev (subdomain Fly.io). Планируется переход на zhanfinance.kz с Cloudflare:
- Cloudflare CDN для статических ресурсов
- Cloudflare Proxy (orange cloud) для защиты от DDoS
- SSL/TLS certificate от Cloudflare
- Page Rules для оптимизации кэширования
