## 11. Онбординг разработчика

### 11.1 Требования к окружению

Для локальной разработки необходимы:
- Java Development Kit 17 (Eclipse Temurin или OpenJDK)
- Node.js 20 LTS или 22+
- Docker Desktop (для PostgreSQL) или локальный PostgreSQL 15+
- Git 2.30+
- IDE с поддержкой Java и TypeScript (IntelliJ IDEA, VS Code)

### 11.2 Клонирование и настройка

```bash
git clone https://github.com/MrSgemaSeny/JF-1C.git
cd JF-1C
```

Структура проекта монорепозитория:
```
JF-1C/
├── zhan-finance-backend/     # Spring Boot приложение
├── zhan-finance-frontend/    # React SPA
├── docker-compose.yml        # Локальное окружение
├── docs/                     # Документация
├── Epics/                    # Планирование
└── .agents/                  # AI-контекст
```

### 11.3 Запуск бэкенда

1. Поднятие базы данных:
```bash
docker compose up db -d
```

2. Создание базы данных PostgreSQL:
```sql
CREATE DATABASE zhan_finance_db;
CREATE USER postgres WITH PASSWORD 'postgres';
GRANT ALL PRIVILEGES ON DATABASE zhan_finance_db TO postgres;
```

3. Настройка переменных окружения в zhan-finance-backend:
Создать .env или настроить application-dev.yml:
```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/zhan_finance_db
spring.datasource.username=postgres
spring.datasource.password=postgres
jwt.secret=your-secret-key-minimum-256-bits
```

4. Запуск приложения:
```bash
cd zhan-finance-backend
./gradlew bootRun
```

При первом запуске Flyway автоматически применит все миграции, а PipelineSeederService создаст стартовые пайплайны.

5. Проверка health:
```bash
curl http://localhost:8080/api/actuator/health
```

### 11.4 Запуск фронтенда

```bash
cd zhan-finance-frontend
npm install
npm run dev
```

Настройка API URL в .env.development:
```properties
VITE_API_URL=http://localhost:8080/api/v1
```

Приложение доступно по http://localhost:5173.

### 11.6 Запуск тестов

Backend tests:
```bash
cd zhan-finance-backend
./gradlew test
```

Frontend type check:
```bash
cd zhan-finance-frontend
npx tsc --noEmit
```

Frontend tests (Vitest):
```bash
cd zhan-finance-frontend
npx vitest run
```

### 11.7 Полезные команды

Обновление зависимостей:
```bash
cd zhan-finance-backend && ./gradlew dependencies
cd zhan-finance-frontend && npm update
```

Очистка и пересборка:
```bash
cd zhan-finance-backend && ./gradlew clean build
cd zhan-finance-frontend && rm -rf node_modules dist && npm install && npm run build
```

Swagger UI:
http://localhost:8080/api/swagger-ui.html
