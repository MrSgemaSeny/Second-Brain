## Приложение Д: Глоссарий

**API (Application Programming Interface)** — набор правил и протоколов для взаимодействия между программами.

**JWT (JSON Web Token)** — стандарт для создания токенов доступа, содержащих заявки (claims) о пользователе.

**TOTP (Time-based One-Time Password)** — алгоритм генерации одноразовых паролей на основе текущего времени.

**2FA (Two-Factor Authentication)** — двухфакторная аутентификация, требующая два типа подтверждения личности.

**CRM (Customer Relationship Management)** — управление взаимодействиями с клиентами и потенциальными клиентами.

**LMS (Learning Management System)** — система управления обучением для создания, доставки и отслеживания образовательного контента.

**FSD (Feature-Sliced Design)** — методология организации кода фронтенд-приложений слоями и фичами.

**Kanban** — метод визуализации работы с доской, где задачи перемещаются между колонками (стадиями).

**Pipeline (воронка продаж)** — последовательность стадий, через которые проходит лид или задача от создания до завершения.

**ADVISOR** — роль с расширенным доступом в CRM-платформе. Имеет сквозной доступ ко всем задачам и клиентам компании для экспертного контроля. Реализован через CrmAccessService с обходом проверки владения.

**Webhook** — механизм уведомления внешних систем о событиях через HTTP-вызовы.

**Webhook endpoint** — URL, на который отправляются webhook-уведомления.

**Rate limiting** — ограничение количества запросов с одного источника за единицу времени.

**Row-level security** — защита на уровне отдельных строк таблицы, а не на уровне таблицы целиком.

**IDOR (Insecure Direct Object Reference)** — уязвимость, когда доступ к объекту определяется только по его ID без проверки прав.

**CORS (Cross-Origin Resource Sharing)** — механизм, позволяющий или запрещающий запросы с других доменов.

**Swagger UI** — интерактивный интерфейс для просмотра и тестирования API по спецификации OpenAPI.

**Flyway** — инструмент для управления версиями схемы базы данных через миграции.

**Caffeine** — высокопроизводительная библиотека кэширования для Java.

**STOMP (Simple Text Oriented Messaging Protocol)** — протокол обмена сообщениями поверх WebSocket.

**SockJS** — библиотека, обеспечивающая WebSocket-like API с fallback-механизмами.

**OAuth2** — протокол авторизации, позволяющий предоставлять доступ к ресурсам без передачи пароля.

**Bcrypt** — алгоритм хеширования паролей с встроенной солью и адаптивной стоимостью.

**HMAC-SHA256** — алгоритм создания кода аутентификации сообщений с использованием криптографической хеш-функции.

**HttpOnly cookie** — cookie, недоступная для JavaScript, что защищает от XSS-атак.

**SameSite** — атрибут cookie,限制ющий отправку cookie в cross-site запросах.

**Bucket4j** — библиотека для реализации rate limiting на основе token bucket algorithm.

**PostgreSQL JSONB** — тип данных для хранения JSON с бинарным представлением и поддержкой индексов.

**Docker container** — изолированная среда выполнения для приложения и его зависимостей.

**GitHub Actions** — платформа CI/CD для автоматизации сборки, тестирования и деплоя.

**Fly.io** — платформа для развёртывания контейнерных приложений.

**GitHub Pages** — хостинг для статических веб-сайтов из репозиториев GitHub.

**UptimeRobot** — сервис мониторинга доступности веб-сайтов и API.

**Prometheus** — система мониторинга и алертинга с поддержкой временных рядов.

**Cloudflare** — CDN и DDoS-защита с дополнительными сервисами безопасности.

**CDN (Content Delivery Network)** — сеть серверов для быстрой доставки статического контента.

**SSL/TLS** — протоколы для шифрования соединений и аутентификации серверов.

**Health endpoint** — эндпоинт, возвращающий статус здоровья приложения.

**Rollback** — откат к предыдущей версии в случае проблем.

**Baseline** — начальная точка для Flyway, с которой начинается отсчёт миграций.

**Migration** — SQL-скрипт, изменяющий схему базы данных.

**Seed/Seeder** — начальные данные, загружаемые при первом запуске приложения.

**Singleton** — паттерн проектирования, гарантирующий единственный экземпляр класса.

**DTO (Data Transfer Object)** — объект для передачи данных между слоями приложения.

**Entity** — объект, представляющий строку в таблице базы данных.

**Mapper** — компонент, преобразующий данные из одного формата в другой.

**Service** — компонент, инкапсулирующий бизнес-логику.

**Controller** — компонент, обрабатывающий HTTP-запросы.

**Repository** — компонент, абстрагирующий доступ к данным.

**Query key** — ключ для идентификации и управления кэшем в React Query.

**Invalidation** — процесс удаления или обновления кэшированных данных.

**Optimistic update** — обновление UI до получения подтверждения от сервера.

**Code splitting** — разделение кода на части для lazy loading.

**Lazy loading** — загрузка компонентов или данных по требованию.

**SSR (Server-Side Rendering)** — рендеринг страниц на сервере.

**SPA (Single Page Application)** — приложение, загружающее контент динамически без перезагрузки страницы.

**Vite** — быстрый инструмент сборки для веб-приложений.

**Tailwind CSS** — utility-first CSS-фреймворк для быстрой стилизации.

**Framer Motion** — библиотека для анимаций в React.

**@dnd-kit** — набор примитивов для реализации drag-and-drop.

**SunEditor** —WYSIWYG-редактор для React.

**Lucide** — библиотека иконок.

**React Query** — библиотека для управления серверным состоянием в React.

**React Router** — библиотека для маршрутизации в React.

**react-i18next** — интеграция i18next для React.

**Vitest** — фреймворк для unit-тестирования JavaScript/TypeScript.

**JUnit 5** — фреймворк для unit-тестирования Java.

**Mockito** — фреймворк для создания mock-объектов в тестах.

**Thymeleaf** — шаблонизатор для Java, часто используемый с Spring.

**OpenHTMLtoPDF** — библиотека для генерации PDF из HTML.

**poi-tl** — библиотека для создания и редактирования Word-документов.

**totp-spring-boot-starter** — стартер для TOTP-аутентификации в Spring Boot.

**OTLP (OpenTelemetry Protocol)** — протокол для передачи метрик и трассировок.
