## Приложение Г: Чеклисты

### Г.1 Чеклист перед деплоем

Перед каждым релизом убедитесь:

**Код:**
- [ ] Все тесты проходят (./gradlew test && npx vitest run)
- [ ] TypeScript компилируется без ошибок (npx tsc --noEmit)
- [ ] Нет ESLint ошибок (npm run lint)
- [ ] Secrets не захардкожены
- [ ] Логи не содержат sensitive данных

**База данных:**
- [ ] Миграция создана (если нужна)
- [ ] Миграция протестирована на локальной БД
- [ ] Rollback-миграция готова (если нужно)
- [ ] Данные сидеров актуальны

**Безопасность:**
- [ ] Input validation работает
- [ ] Rate limiting настроен
- [ ] CORS настроен правильно
- [ ] HTTPS работает на production

**Функциональность:**
- [ ] Основные user flows протестированы
- [ ] Edge cases обработаны
- [ ] Error states отображаются корректно
- [ ] Лоадеры показываются во время запросов

**Инфраструктура:**
- [ ] Health check endpoint отвечает
- [ ] Метрики собираются
- [ ] Бэкап прошёл успешно
- [ ] Логи доступны

### Г.2 Чеклист code review

При проверке pull request:

**Функциональность:**
- [ ] Код решает описанную задачу
- [ ] Edge cases обработаны
- [ ] Нет regression для существующего функционала

**Безопасность:**
- [ ] Нет SQL-инъекций
- [ ] Нет XSS-уязвимостей
- [ ] Нет чувствительных данных в логах
- [ ] Права доступа проверяются
- [ ] Input validation присутствует

**Качество кода:**
- [ ] Код читаем и понятен
- [ ] Нет дублирования
- [ ] Имена переменных осмысленные
- [ ] Комментарии объясняют "почему", не "что"
- [ ] Нет TODO/FIXME/HACK

**Производительность:**
- [ ] Нет N+1 запросов
- [ ] Индексы добавлены при необходимости
- [ ] Кэширование используется где нужно
- [ ] Нет блокирующих операций в hot path

**Тесты:**
- [ ] Unit-тесты покрывают основную логику
- [ ] Тесты проверяют happy path
- [ ] Тесты проверяют error cases
- [ ] Тесты не зависят друг от друга

### Г.3 Чеклист incident response

При обнаружении инцидента:

**Диагностика:**
- [ ] Определена зона влияния
- [ ] Определено время начала
- [ ] Определены затронутые пользователи
- [ ] Собраны логи и метрики

**Изоляция:**
- [ ] Инцидент локализован
- [ ] Распространение остановлено
- [ ] Критичные системы защищены

**Коммуникация:**
- [ ] Затронутые пользователи уведомлены
- [ ] Команда проинформирована
- [ ] Management уведомлен (если нужно)

**Устранение:**
- [ ] Root cause найден
- [ ] Исправление применено
- [ ] Проверено, что исправление работает

**Пост-инцидент:**
- [ ] Incident report создан
- [ ] Lessons learned проведён
- [ ] Action items назначены
- [ ] Мониторинг усилен
