# Концепция: Гибридные RAG-системы (Dense + Sparse FTS)

## Определение
Гибридный RAG (Retrieval-Augmented Generation) — архитектурный паттерн извлечения контекста для LLM, сочетающий:
1. **Dense Retrieval** — поиск по смысловой близости векторов эмбеддингов (Cosine Similarity, HNSW индексы в `pgvector`).
2. **Sparse Retrieval** — традиционный полнотекстовый поиск по ключевым словам (Lexical Search, `tsvector` в PostgreSQL или BM25).

## Алгоритм объединения: Reciprocal Rank Fusion (RRF)
RRF нормализует ранги из обоих источников без необходимости калибровки абсолютных скоров:

$$RRF(d) = \sum_{m \in M} \frac{1}{k + r_m(d)}$$

где $k \approx 60$, а $r_m(d)$ — порядковый номер документа в выдаче метода $m$.

## Применение в проектах
- **MrDevCourses**: Поиск ответов AI-тьютором по конспектам уроков и фрагментам кода.
- **MeDev**: Семантический поиск по навыкам и проектам в базе кандидатов.
