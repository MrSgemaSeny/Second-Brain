# Brain's Protocol

Второй мозг Мурата Орынбасара. Живой контекст для AI-сессий.

## Правило №1
Перед началом любой сессии AI читает:
- context/me.md
- context/projects.md
- context/prompts_for_ai.md
- context/rules.md

## Правило №2
После успешных тестов и перед git push AI обязан:
1. Открыть journal/YYYY-MM-DD/
2. Создать или обновить файл {project-name}.md
3. Записать: что изменено, что добавлено, что удалено, почему

## Правило №3
AI обязан дополнять prompts_for_ai.md каждый раз, когда
обнаруживает новый паттерн работы или новое правило.

## Структура
- `context/` — системные настройки и правила ИИ (System Prompt)
- `projects/` — обзор каждого проекта (разделены на модульные папки)
- `journal/` — ежедневные логи по датам (Working Memory)
- `knowledge/` — База Знаний (Zettelkasten), хранит паттерны, архитектурные решения и хаки
- `inbox/` — буфер обмена для сырых идей и заметок, ожидающих сортировки
- `templates_for_projects/` — шаблоны для новых проектов
