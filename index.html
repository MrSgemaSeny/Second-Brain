Системные барьеры solo-разработки

Проблемы, из-за которых AI-кодинг без регламента превращается в хаос и технический долг.

Контекстный налог

Каждую сессию приходится заново объяснять AI свой стек, ОС, версии библиотек и архитектуру.

Амнезия решений

AI пишет код «в вакууме», не зная причин прошлых архитектурных выборов и отброшенных вариантов.

Повтор грабель

Ошибки миграций, Flyway, RateLimiting и N+1 отлаживаются с нуля в каждом новом проекте.

Слепые коммиты

Коммиты «fix bug» без журнала сессии хоронят контекст изменений и ломают воспроизводимость.

Три железных правила протокола

Обязательный порядок действий для любого AI-агента в репозитории.

Правило 01

Чтение context/* на старте

Перед первой строчкой кода AI загружает профиль инженера, ограничения и действующие ADR.

Правило 02

Лог в journal/ до Git Push

Только после зеленых тестов агент обязан создать отчет сессии. Hooks блокируют push без записи.

Правило 03

Синхронизация knowledge/

Найденный редкий баг или оптимизация сразу заносятся в базу знаний для следующих сессий.

Главная формула системы

1. ТЕСТЫ ПРОШЛИ ➜ 2. AI ПИШЕТ В ЖУРНАЛ ➜ 3. GIT COMMIT / PUSH
Никогда наоборот. Никогда без лога. Слепой пуш без прогона тестов и отчета сессии разрушает инженерную историю и накапливает невидимый долг.
Кумулятивный эффект Каждая завершенная сессия делает кодовую базу и контекст умнее для следующего диалога с AI.

Топология Second Brain

Строгая файловая структура для хранения и передачи контекста.

Zettelkasten + ADR
context/

Живой контекст и профиль

me.md — стек (Spring Boot 3, React 19, FSD, PostgreSQL), цели, уровни зрелости проектов и принципы.

decisions/

Архитектурные решения (ADR)

Фиксация «почему выбрана эта библиотека»: модульный монолит, Flyway-миграции, JWT в Redis.

journal/

Хронология инженерных сессий

Ежедневные структурированные отчеты: решенные задачи, результаты тестов, баги и закрытые риски.

knowledge/

Zettelkasten база знаний

Готовые рецепты: решение проблем Flyway, Spring AI RAG, WebSockets, Deslop-скиллы и FSD-паттерны.

projects/

Карта активных проектов

Статусы, роадмапы и чек-листы по проектам (MrDevCourses, MeDev, Valeur, JF-1C).

scripts/

Автоматизация контекста

Скрипты combine.py и combine.ps1 для моментальной склейки контекста в один файл для AI-агентов.

Сравнение: Хаос vs Brain's Protocol

Практический результат для ежедневной разработки.

Сценарий Без протокола (Хаос) С Brain's Protocol
Старт сессии 10-15 минут объяснять AI стек и архитектуру 3 секунды (AI читает context/me.md)
Архитектурный выбор AI спонтанно предлагает микросервисы «потому что модно» Модульный монолит строго по ADR
Повторные баги Ошибки RateLimiting отлаживаются в 3-й раз с нуля Готовое решение берется из knowledge/
Контроль коммитов Слепой коммит «fix bug», контекст утерян Hooks требуют зеленые тесты и лог в journal/
