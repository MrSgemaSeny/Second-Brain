# Phase 8: Frontend Core & API Integration

## Что сделано
1. Бэкенд: Добавлены поля `status`, `format`, `experience_level`, `expires_at` в `Vacancy` (migration `V2__add_vacancy_fields.sql`).
2. Бэкенд: Обновлен `VacancyController` (`changeVacancyStatus`) и `VacancyService` для поддержки фильтрации по `status`.
3. Фронтенд: Интеграция `TanStack Query` для вакансий (`useVacancyQueries.ts`) и откликов (`useApplicationQueries.ts`).
4. Фронтенд: Отрефакторен `MyVacanciesPage.tsx` для использования новых API хуков вместо `db_helper`.
5. Фронтенд: Отрефакторены `CreateVacancyForm.tsx` и `useVacancyActions.ts` (заменен `db_helper` на серверные запросы).
6. Фронтенд: Отрефакторен `FeedPage.tsx` (заменен `useVacancies` на `usePublicVacancies`).
7. Фронтенд: Отрефакторен `VacancyDetailPage.tsx` (используется `useVacancyDetails` и `useCreateApplication`).
8. Компиляция: Фронтенд `npm run build` проходит успешно. Бэкенд-сервисы (`vacancy-service`, `application-service`, `identity-service`, `api-gateway`, `ai-service`) компилируются успешно.

## План на следующую сессию (Phase 9)
- Интеграция AI: Генерация саммари резюме через `ai-service`
- Rate limit UI на фронтенде
- Трекинг использования токенов

## Важные замечания
- На фронтенде всё ещё используется заглушка для Match Score (`85%`) из-за отсутствия полного AI-скоринга в API. Это будет исправлено в Phase 9.
