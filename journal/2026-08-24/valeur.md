# Сессия 2026-08-24 — Valeur (Миграция монолита на микросервисы)

## Текущий реальный статус: Level 2 — Pet Project / MVP Migration

Архитектурный фундамент микросервисной платформы поднят локально через Docker Compose.

---

### 1. Архитектура и сервисы
- `api-gateway` (8080): Spring Cloud Gateway, валидация JWT, форвардинг заголовков (`X-User-Id`, `X-User-Role`, `X-Tenant-Id`).
- `identity-service` (8081): регистрация, аутентификация, тенанты (компании), ротация JWT.
- `vacancy-service` (8082): управление вакансиями и требованиями.
- `application-service` (8083): обработка откликов, статусы кандидатов.
- `ai-service` (8084): скоринг и саммари через Groq API (Llama 3.3 70B).
- `frontend` (5173): React 19 + TypeScript + Vite + Tailwind v4 + FSD, нативный `fetch`, TanStack Query v5.

---

### 2. Безопасность и изоляция
- Межсервисное взаимодействие через `RestClient` с валидацией `X-Internal-Token` (`InternalTokenFilter`).
- Мультитенантная изоляция на уровне БД по `tenant_id` и `TenantContext` (ThreadLocal).

---

### 3. Бэклог и следующие шаги
- Завершение миграции интерфейса (экраны вакансий, авторизация, отклики).
- Покрытие тестами всех микросервисов.
- Подготовка к полноценному сквозному тестированию.
