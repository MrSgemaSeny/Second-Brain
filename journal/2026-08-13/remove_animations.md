# Удаление анимаций с карточек тарифов

## Изменения
Пользователь запросил убрать анимации, чтобы дизайн был максимально строгим, в стиле GitHub.
1. В `PricingPage.tsx` из трех карточек тарифов (внутри полноэкранного оверлея) удалены CSS классы `transition-all duration-200 hover:-translate-y-1 hover:shadow-xl`.
2. Карточки стали полностью статичными, без эффекта поднятия при наведении мыши.
