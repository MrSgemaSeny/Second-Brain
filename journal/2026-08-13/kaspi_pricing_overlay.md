# Полный экран для выбора плана PRO (Overlay)

## Изменения
Пользователь запросил сделать процесс выбора срока подписки (1, 3, 6 месяцев) "на всю страницу" в стиле современных SaaS сервисов.
1. Убран старый компонент `Modal.tsx` из `PricingPage.tsx`.
2. Написан кастомный полноэкранный overlay (`fixed inset-0 z-[100]`), который появляется поверх всего приложения.
3. Внутри оверлея размещены три большие карточки с тарифами (1, 3, 6 месяцев).
4. Настроен скролл для мобильных устройств, центрирование и анимация появления.
5. Закрытие реализовано через "Escape" или кнопку-крестик в шапке оверлея.
6. Выдержан строгий стиль GitHub Dark Mode без лишних цветов (зеленый акцент используется только в самом выгодном плане и кнопке оплаты для привлечения внимания, но общая канва строго черно-серая).
