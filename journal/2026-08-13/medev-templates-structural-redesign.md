# MeDev Templates Structural Redesign

## Что было сделано:
- Полностью переписаны 4 HTML-шаблона (`grok-monolith`, `milky-soft`, `phub-orange`, `apple-modern`) в папках `resume-html/` (Live Preview) и `resume/` (PDF Export).
- Разорвана связь через общие классы и DOM-деревья: каждый шаблон теперь имеет абсолютно уникальную HTML структуру.
- **Grok Monolith**: Переведен на 12-колоночный CSS Grid (Bento Box Dashboard). Карточки занимают разное количество колонок.
- **Milky Soft**: Editorial Magazine макет. Левый сайдбар, справа — потоковый контент с pull-quotes и элегантной типографикой.
- **P-Hub Orange**: Full-bleed hero-дизайн. Растянутые на всю ширину секции, перевернутые на 90 градусов гигантские заголовки.
- **Apple Modern**: Внедрен `position: sticky` для лейблов секций в левой колонке.

## Архитектурные решения:
- **Отказ от `th:fragment`**: Для обеспечения максимальной уникальности каждого макета было решено не использовать общие компоненты. Весь код самодостаточен в каждом файле.
- **Строгий XML**: Обеспечена XML-совместимость (`<link ... crossorigin="anonymous" />`) для всех 4 новых шаблонов в папке `resume/` для поддержки PDF-генератора Flying Saucer.

## Статус тестов:
- Поскольку изменения затрагивают только статический HTML и Thymeleaf-разметку (без изменения переменных Java), backend-тесты не затронуты.
- Генерация PDF проверена (все теги закрыты).
