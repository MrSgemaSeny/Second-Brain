# 2026-08-13: Stripe Mock Mode

## Сделано
В `StripeService.java` добавлена заглушка для локальной разработки (Mock Mode). Если `stripeApiKey` отсутствует или содержит значение по умолчанию `12345`, сервис мгновенно переводит пользователя на `PRO` план без запроса к реальному API Stripe и возвращает успешный URL с фейковым `session_id`. Это решает проблему ошибки 500 (Internal Server Error) при тестировании функции Checkout без проброшенных ключей Stripe.
