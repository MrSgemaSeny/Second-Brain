# Окончательное удаление анимаций из UI тарифов

## Изменения
По запросу пользователя убраны абсолютно все эффекты анимации из процесса выбора тарифа:
1. Удалены CSS классы (hover, translate, shadow) с карточек 1/3/6 месяцев в полноэкранном оверлее.
2. Удален класс `animate-in fade-in duration-200` с самого контейнера оверлея (`fixed inset-0`).
3. Теперь при клике на "Upgrade to PRO" экран моментально и жестко перекрывается оверлеем без малейших задержек или эффектов плавного появления, что соответствует строгому техническому стилю (GitHub/Terminal).
