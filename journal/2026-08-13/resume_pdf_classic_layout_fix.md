# Fix PDF Layout for Classic Template

**Date:** 2026-08-13
**Project:** MeDev
**Status:** Completed

## Проблема
Библиотека Flying Saucer (ITextRenderer) не поддерживает современные CSS-свойства (flexbox, grid). Из-за этого шаблон `classic.html` мог отображаться некорректно в PDF-формате, если использовались `div` с flex-свойствами для структуры (например, заголовки секций с датами справа).

## Решение
- В файле `backend/src/main/resources/templates/resume/classic.html` структура элементов заменена на `<table>` для гарантии правильного выравнивания.
- Убраны `div` с классами `.item-header` и заменены на `<table class="layout">`, чтобы даты и позиции выравнивались корректно по левому и правому краю.
- Заменены символы-разделители `|` на `&bull;` для большей эстетики.
- Проверка на наличие навыков и проектов обернута в таблицы.

## Риски
- Минимальные. Влияет только на отображение `classic` шаблона в PDF. Требуется ручная проверка генерации пользователем.
